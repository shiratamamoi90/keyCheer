# 論点 0056: 計測の機能を配布物から外す

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: —**(配布物の中身の決定で、要件に及ばない。結果はビルドの設定に現れる)

## 何を決めるか

人間の指示(2026-11-21):**計測の機能はアプリに要らない。配布物から外すだけにして、リポジトリには残す**
(開発機で過去の baseline と比べられるようにする)。

いまは `tsconfig.build.json` が `src/**/*.ts` をすべてビルドするので、`src/eval` が `dist/eval` に出て、
electron-builder の `files`(`dist/**/*`)で配布物に入っている。`npm run eval` は `tsx` で `src/eval` を直に動かすので、
配布用のビルドは使っていない。

## 案

| | 案A:配布用のビルドから `src/eval` を除く | 案B:ビルドはそのままにし、electron-builder の `files` で `dist/eval` を除く |
| --- | --- | --- |
| 確実さ | 作られないので入らない | 作ってから除く。除き忘れの余地がある |
| 型の検査 | `npm run typecheck`(`tsconfig.json`)は今までどおり eval も見る | 同じ |

## `[要確認]`

- 案A・案B のどちらにするか。

## 決定

**配布用のビルド(`tsconfig.build.json`)の対象から `src/eval` を除く(案A)。** `src/eval`・`tests/eval`・`npm run eval` はリポジトリに残し、
開発機で過去の baseline と比べられるようにする。人間の判断(2026-11-21)。

## 理由

- 人間の方針:計測の機能はアプリに要らない。ただし過去の論点の計測を再現できるよう、リポジトリには残す。
- 作らなければ入らない。electron-builder の `files` で除く案は、作ってから除くので除き忘れの余地がある。
- `npm run eval` は `tsx` で `src/eval` を直に動かすので、配布用のビルドから外しても計測は変わらない。

## 却下した案

- **electron-builder の `files` で `dist/eval` を除く(案B)** — 作ってから除くので、設定の書き忘れで入りうる。
- **リポジトリから削除する** — 過去の論点の計測(baseline との比較)を再現できなくなる。

## 決まらなかったこと(次の論点へ)

- 無し。アプリ側(main / renderer / agent)が `src/eval` を import していないことは、ビルドが通るかで分かる。
