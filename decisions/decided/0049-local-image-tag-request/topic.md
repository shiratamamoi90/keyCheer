# 論点 0049: local-sdcpp の画像タグは、待機画像で見た目を、ほかの 2 枚で表情とポーズを訊く

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/integrations.md`**(S0049_01〜03)

## 何を決めるか

論点 0045 は、ローカル画像生成の作り方として「待機画像の画像タグは見た目(髪・服など)、`regular`・`milestone` の画像タグは
表情とポーズ」と決めた(決定 3・4)。計測もその形の要求で行った。ところが論点 0046 で要件に書き起こすとき、エージェントが
「要求の文面は品質の話なので要件にしない」とし、アプリは以前のまま 3 枚とも「表情・ポーズ・雰囲気」を訊いていた
(2026-11-13 の整合の確認で見つかった)。このままだと、待機画像の見た目がテキストモデル任せにならず決まらないうえ、
計測で確かめた絵と違う絵になる。

文面の一字一句は品質の話だが、**何を訊き、何を訊かないか**は決定的に縛れる。ここでそれを要件にする。

## 案

| | 案A:`local-sdcpp` だけ訊くことを変える | 案B:全部の画像プロバイダーで変える |
| --- | --- | --- |
| 待機画像 | 見た目(人物の語・髪・目・服)を訊く | 同じ |
| ほかの 2 枚 | 表情とポーズだけを訊く(見た目は待機画像のものを使う) | 外部は 3 枚を別々に作るので、見た目が入らないと 3 枚が別人になる |
| 外部の画像プロバイダー | 今のまま | 作り方ごと変える必要がある(論点 0046 で「外部は変えない」と決めた) |

## 決定

人間が承認(2026-11-13)。案A。

1. `local-sdcpp` の待機画像の画像タグの要求は、キャラクターの**見た目**を訊く。人物の語(`1girl` か `1boy`)・髪の色・髪型・目の色・服装。
   セリフは入れない(S0036_02 のまま)。
2. `local-sdcpp` の `regular`・`milestone` の画像タグの要求は、その応援種別のセリフを示して、**表情とポーズだけ**を訊く。
   髪・目・服は訊かない(待機画像の画像タグを使うため。S0046_03)。
3. 外部の画像プロバイダーでは、要求を変えない。
4. 要求の文面は、論点 0045 の計測で使ったものにする(計測ドライバ `src/eval/imageProcessComparison.ts` と同じ文)。
   文面そのものは要件にせず、訊くもの・訊かないものだけを要件にする。

## 理由

- 論点 0045 の決定 3・4 をそのまま反映するため。計測で絵を確かめたのはこの形の要求だけ。
- 待機画像で見た目を決めておかないと、応援種別の画像に足す「待機画像の画像タグ」(S0046_03)が表情やポーズの語になり、
  描き直しで人物を保つ役に立たない。
- 外部を変えないのは論点 0046 の決定のとおり。

## 却下した案

- 案B — 外部は 3 枚を別々に文字から作る。表情とポーズだけの要求にすると見た目の手がかりが無くなる。
- 今のまま(3 枚とも「表情・ポーズ・雰囲気」)— 決めた作り方と違い、計測していない絵になる。

## 決まらなかったこと(次の論点へ)

- 外部の画像プロバイダーの画像タグに見た目が入らない問題(論点 0041 の `result.md`「モデルの差ではない問題」2)は残っている。
- 画像タグの質(テキストモデルが画像モデル向きでない語を出す)は非決定的で、ここでは縛らない。
