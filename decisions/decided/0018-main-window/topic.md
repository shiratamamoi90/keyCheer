# 論点 0018: メインウィンドウの開閉ライフサイクル

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/main-window.md`**

## 何を決めるか

キャラ作成 UI・設定 UI を載せる「入れ物」の開閉規則。閉じるを終了と同一視するかどうかも含む。

## 決定

- **キャラ未作成で起動したら自動表示**する(作る手段に到達できないことを防ぐ)。
- トレイからトグルで開閉する。**閉じるは破棄せず hide** し、常駐は続ける。
- 重複表示を防ぎ、ウィンドウは単一インスタンスとする。
- **発動経路とは独立**:応援の発動はメインウィンドウの有無に影響されない。
- メインウィンドウの renderer も `providers` を import しない。

## 理由

常駐アプリなので、閉じる = 終了にすると応援が止まってしまう。
一方でキャラ未作成のまま起動すると何も起きないアプリに見えるため、初回だけは自動で出す。

## 却下した案

- 閉じるで終了する — 常駐前提と矛盾するため却下。
- 起動時に常に表示する — 2回目以降は邪魔になるため却下。
