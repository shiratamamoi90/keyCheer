# 論点 0070: 設定画面で応援の回数・秒数・節目を変えられるようにする

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/main-window.md`**(S0070_01〜09)。前提は論点 0071

## 何を決めるか

論点 0009 でトリガー設定(`triggers.regular` / `triggers.activeThresholdSec` / `triggers.milestones`)を
設定できる値にし、値域の検証・保存・即時反映は実装済み。ただし画面が無く、いまは設定ファイルを直接書き換えるしかない。
論点 0009 は「設定 UI が 1 タブ増える」とだけ書き、画面の振る舞いを要件にしていなかった(作業 0002 が止まっていた理由)。

決めること:どこに置くか / 何を変えられるか / 値域の外をどう扱うか。前提は論点 0071(節目を 1 つの回数にする)。

## 案

| | 案A:設定画面に足す | 案B:4 つ目のタブ |
| --- | --- | --- |
| 画面の数 | 3 のまま(論点 0061) | 4 に増える |
| ほかの設定と | 同じ画面・同じ保存のしかた | 別の画面 |

| 値域の外 | 案X:入力の段階でその値にできない | 案Y:保存を止めてエラーを出す |
| --- | --- | --- |
| 利用者 | 不正な値を作れない | 作れるが保存できない |
| エラーの表示 | 要らない | 要る |

## 決定

人間が選んだ(2026-11-25):**案A + 案X**。1〜3 は人間の指示、4〜7 はエージェントが補い、人間が承認した(2026-11-25)。

1. 設定画面に「応援」の欄を足す(タブは増やさない)。
2. 変えられるのは 3 つ:通常の応援の回数(`triggers.regular`)・止まった扱いにするまでの秒数(`triggers.activeThresholdSec`)・
   節目の回数(`triggers.milestoneInterval`。節目は 1 つの回数にする — 論点 0071)と、節目の応援を出すか(`triggers.isMilestoneEnabled`)。
   既定値は今のまま(50 / 60 / 250 / 出す)。画面には保存されている値を出す。
3. 値域(回数 1〜10000 / 秒数 5〜600 / 節目 `回数 + 1`〜100000。論点 0071)の外の値には、画面の操作でできないようにする。
4. 回数・秒数・節目は数を入れる欄にする。入力を確定したとき(欄から離れる・Enter)、範囲より小さければ下限に、大きければ上限に寄せ、小数は切り捨てて整数にする。
   空や数でない入力は、確定したときに保存されている値に戻す。
   回数の上限は `節目 - 1`(10000 より小さければ)、節目の下限は `回数 + 1` にする — 回数を節目以上に、節目を回数以下にできない。節目の応援を出さない間もこの範囲は同じ。
5. 確定したらすぐ保存する(ほかの設定と同じく保存ボタンは置かない)。保存したら次の打鍵から効く(既存の即時反映。S0009 系)。
   入力の途中(確定する前)は保存しない。
6. 節目の応援を出すかは切り替えのスイッチにする(ほかの設定と同じ)。出さない間は節目の回数の欄を押せない形にする(値は残る)。
7. 応援の欄の変更は、ほかの設定(表示・テーマ・生成)と保存データ(キャラクター・統計)を変えない。
   main 側の値域の検証(S0033_15)はそのまま残す(画面を通らない書き換えを防ぐため)。

## 理由

- 案A:応援の頻度も「設定」であり、論点 0061 で画面を 3 つにまとめたのを崩さない。
- 案X:値域の外を作れなければ、エラーの表示も「保存できなかった値をどうするか」も要らない。
- 4:数の欄で 1 文字ずつ打つ途中(例 1000 を打つ途中の 1)を値域で弾くと打てなくなるので、確定したときに寄せる。

## 却下した案

- 案B — 設定がタブごとに散らばり、論点 0061 のまとめ方と合わない。
- 案Y — 不正な値を作らせてから断るより、作れないほうが分かりやすい(人間の指示)。
- 入力のたびに保存する — 打つ途中の値が保存され、応援の頻度が一瞬変わる。
- 節目を回数の一覧で編集する — 人間の指示で節目を 1 つの回数にした(論点 0071)。

## 決まらなかったこと(次の論点へ)

- 既定値に戻す操作は置かない(指示に無い)。要るなら別の論点で決める。
