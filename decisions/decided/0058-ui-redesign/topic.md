# 論点 0058: メインウィンドウの見た目をモダンに作り直す

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: —**(見た目は仕様にしない。決めるのは作り方の方針と依存で、結果はコードに現れる)

## 何を決めるか

人間の指示(2026-11-21):**アプリの UI が汚いので、モダンな感じにきれいにする。**

見た目の良し悪しは要件にもテストにもしない(doc-rules「何を仕様化するか」)。**画面の振る舞い(`docs/main-window.md` ほかの
シナリオ)は変えない** — 変えるものが出たら、その分だけ別の論点にする。ここで決めるのは、後から「なぜこうなっているか」と訊かれる 2 点:

1. **スタイルの書き方。** いまは `main.html` の `<style>` に手書きの CSS。`tailwindcss` 3.4.17 は devDependencies に入っているが使われていない。
2. **新しい依存を入れるか**(部品のライブラリ・アイコン・フォント)。入れるなら審査を記録する(security-rules「依存・サプライチェーン」)。

ダークモード(論点 0057)が入るので、色は名前を付けた変数(CSS 変数)にまとめ、ライトとダークで差し替える形にする。

## 案

### 1. スタイルの書き方

| | 案A:手書きの CSS を CSS 変数で整理し直す | 案B:Tailwind を使う(ビルドで CSS を作る) |
| --- | --- | --- |
| 依存 | 増えない | 既にある依存を使う。`npm run build` に Tailwind の CLI を足す(バンドラは要らない) |
| 書き方 | クラス名を自分で付ける | React.createElement の `className` にユーティリティを並べる |
| ダークモード | CSS 変数の差し替え | `darkMode: "class"` |

案B にするなら、`tailwindcss` を devDependencies から消すかどうかの判断も不要になる。案A なら、使っていない `tailwindcss` を消す。

### 2. 依存

| | 案A:増やさない(OS のフォント・自前の SVG アイコン) | 案B:アイコン集などを入れる |
| --- | --- | --- |
| 備考 | 配布物が大きくならず、審査が要らない | 入れるものごとに出所・ライセンスを審査する |

### 3. 方向性(人間に見てもらうもの)

「モダン」の中身は人間の好みなので、作る前に方向を 1 つ選んでもらう。例:

- カード型(白い面に影と角丸、余白を広めに。Windows 11 の設定画面に近い)
- 平らな面(線で区切る。情報を詰めて並べる)

## 決定

1. **スタイルは Tailwind(既に devDependencies にある `tailwindcss` 3.4.17)で書く。** `npm run build` で Tailwind の CLI が CSS を作る
   (バンドラは使わない方針のまま)。色は名前を付けた変数にまとめ、ライトとダーク(論点 0057)で差し替える。
2. **新しい依存は入れない。** フォントは OS のもの(Yu Gothic UI / Segoe UI)、アイコンは自前の SVG。
3. **方向はカード型**(Windows 11 の設定画面に近い。角丸の面と薄い影、余白を広めに)。
4. **画面の振る舞い(`docs/` のシナリオ)は変えない。** 見た目だけを作り直す。振る舞いを変えたくなったら、その分だけ別の論点にする。
5. 作る前に 1 画面の見本を人間に見てもらい、よければ全体に広げる。

人間の判断(2026-11-21):1 は Tailwind、2 は増やさない、3 はカード型。

## 理由

- Tailwind は既に入っていて、新しい依存の審査が要らない。ダークモードも `dark:` で素直に書ける。
- 依存を増やさなければ、配布物が大きくならず、出所の審査も要らない(security-rules「依存・サプライチェーン」)。
- カード型は Windows 11 になじみ、キャラクターの 3 枚の画像(論点 0050)を並べる面として使いやすい。
- 見た目は好みなので、全体に広げる前に見本で確かめる。

## 却下した案

- **手書きの CSS を CSS 変数で整理し直す** — 人間が Tailwind を選んだ。手書きでは揃った見た目を保つ手間が大きい。
- **アイコン集などの依存を入れる** — 審査と配布物の大きさの費用に見合わない。
- **平らな面(線で区切る)** — 人間がカード型を選んだ。

## 決まらなかったこと(次の論点へ)
