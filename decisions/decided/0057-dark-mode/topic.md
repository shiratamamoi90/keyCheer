# 論点 0057: ダークモード(OS の設定に合わせ、手で切り替えられる)

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/main-window.md`・`docs/data-model.md`・`docs/glossary.md`**

## 何を決めるか

人間の指示(2026-11-21):**ダークモードを足す。既定は OS(Windows)の設定に合わせ、設定タブで「システム / ライト / ダーク」を選べる。**

見た目(色そのもの)は仕様にしない。決めるのは外から見える約束:設定項目の名前と値・既定値・どの画面に効くか・いつ反映するか。

設定項目(見込み):`ui.theme` = `"system"` / `"light"` / `"dark"`、既定 `"system"`。
`"system"` のとき、OS の設定が変わったら開いている画面にすぐ反映する。値の変更も、開いている画面にすぐ反映する。
定義域外の値は読み込み時に既定へ戻す(既存の設定の検証・移行のやり方に合わせる)。

## 案

### 1. どの画面に効かせるか

| | 案A:メインウィンドウだけ | 案B:メインウィンドウとキャラの窓のセリフの吹き出し |
| --- | --- | --- |
| 備考 | キャラの窓は透明で、絵はテーマで変わらない | 吹き出しも暗くなる。デスクトップの壁紙によっては読みにくくなることがある |

### 2. 同意ダイアログ・確認ダイアログ

ローカル限定(論点 0054)で同意ダイアログは無くなる見込み。作り直しの確認(論点 0038)はメインウィンドウの中なら、メインウィンドウと同じにする。
OS のダイアログを使っているなら、OS の設定に従う(アプリの設定では変わらない)。`[要確認]` — どちらを使っているかは実装を見て報告する。

## 決定

1. 設定項目 `ui.theme` を足す。値は `"system"` / `"light"` / `"dark"`、既定 `"system"`。用語集の語は「テーマ」(`theme`)。
2. `"system"` のときは OS(Windows)の設定に合わせ、OS の設定が変わったら開いているメインウィンドウにすぐ反映する。
   設定画面で値を変えたら、再起動しなくてもすぐ反映する。
3. **効かせるのはメインウィンドウだけ。** キャラの窓(絵とセリフの吹き出し)はテーマで変えない。
4. 作り直しの確認ダイアログは OS のダイアログのままにし、アプリのテーマでは変えない(OS の設定に従う)。
5. 無い・定義域外の保存値は `"system"` として扱い、保存値は書き換えない(既存の設定の読み込みと同じ扱い。S0053_07 など)。
   renderer からの定義域外の値は main 側で拒否する(S0033_15 と同じ扱い)。

人間の判断(2026-11-21):1 はそれでよい、3 はメインウィンドウだけ、4 は OS のまま。

## 理由

- 人間の指示:既定は OS に合わせ、手でも切り替えられる。
- 吹き出しはデスクトップの上に出るので、壁紙によって暗い吹き出しが読みにくくなる。読みやすさを優先して今のままにする。
- 確認ダイアログを作り替えると、見た目のためだけに作りが増える。OS のダイアログは OS のダーク設定に従うので、`"system"` の利用者には揃って見える。

## 却下した案

- **吹き出しにもテーマを効かせる** — デスクトップの上で読みにくくなることがある。
- **確認ダイアログをアプリの中のものに替える** — 作りが増える割に得るものが小さい。

## 決まらなかったこと(次の論点へ)

- 色そのもの・見た目は仕様にしない(論点 0058 の作り方の方針に従う)。
