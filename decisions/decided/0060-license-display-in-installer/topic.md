# 論点 0060: ライセンスはインストーラだけに示す

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/licenses.md`**

## 何を決めるか

人間の指示(2026-11-21):**ライセンスはインストーラに出すだけでいい。**

いまアプリの中には次の表示がある、または予定している。

- 設定画面の、画像の重みのライセンスと利用の制限(S0047_01。実装済み)
- 設定画面の「ライセンスとクレジットの表示」(S0043_01 / 02 / 05 / 06。未実装):VOICEVOX ENGINE の LGPL v3・Ollama などの MIT・npm の依存の一覧・話者 4 つのクレジット
- 話者を選ぶ所の、その話者のクレジット表記(S0043_03。未実装)

どこまでをインストーラに寄せるかを決める。

## 案

| | 案A:ライセンスは全部インストーラ、話者のクレジットだけアプリに残す | 案B:アプリの中には何も出さない | 案C:画像の重みの表示だけやめる |
| --- | --- | --- | --- |
| 設定画面 | ライセンスの表示を出さない | 出さない | VOICEVOX ほかは予定どおり出す |
| 話者を選ぶ所のクレジット | 出す | 出さない | 出す |
| VOICEVOX の規約 | 話者の規約が求めるクレジットを、声を選ぶ所で示せる | 利用者が規約に気づく場所がインストーラだけになる | — |

## 決定

**案A。** ライセンス(同梱物すべての全文・画像の重みの利用の制限・npm の依存の一覧)はインストーラの画面にだけ示す。
アプリの中にはライセンスの表示を置かない。話者を選ぶ所のクレジット表記(S0043_03)だけはアプリに残す。

- 廃止:S0043_01 / S0043_02 / S0043_05 / S0043_06 / S0047_01(欠番)。
- S0043_04(通信しない)は、話者を選ぶ所のクレジット表記だけに当てる。
- 新しい要件:S0060_01(インストーラがライセンスを示す)/ S0060_02(アプリの中にライセンスの表示を出さない [否定])。
- 画像の重みの同意(S0047_02 / S0047_03。インストーラ)は変えない。

人間の判断(2026-11-21):案A。

## 理由

- 人間の指示。インストーラは画像の重みの同意(論点 0047 / 0055)でライセンスと利用の制限を既に示すので、全文を並べる場所として揃う。
- 話者のクレジットはライセンスではなく、話者の規約が求める表記。声を選ぶ所で示すのが、生成した音声を外で使う人に届く場所になる。

## 却下した案

- **アプリの中には何も出さない** — 人間がクレジットだけ残す案を選んだ。話者の規約に気づく場所がインストーラだけになる。
- **画像の重みの表示だけやめる** — 人間の指示(ライセンスはインストーラだけ)と合わない。

## 決まらなかったこと(次の論点へ)

- LGPL v3 の満たし方(ライセンス文と、同梱した版のソースの入手先を利用者に届ける)を、インストーラの表示だけで満たせるかは、
  配布の前に人間が原文で確かめる(論点 0043 の宿題と同じ)。
