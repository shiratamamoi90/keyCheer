## ゾーン名の漏れ(現行の不具合)

zone_line では、プロンプトのゾーン名 `slow` / `normal` / `fast` が応援文にそのまま出た。

| | zone_line | no_zone_line |
| --- | --- | --- |
| ゾーン名を含む文(層 3 の後) | 88 / 2784 文(3.2%) | 0 / 2820 文 |
| それを含むバケット | 35 / 360(9.7%) | 0 / 360 |
| キャラ別のバケット数 | チア 23・レン 7・シズク 5 | — |

出方は `-slow--` だけの文、`-normal-- 午後の作業も頑張ろう!` のような前置き、など。
層 3 の後でも残るので、**今のアプリでもプールに入りうる**。書式混入率 3.7% の大半(行頭記号 93 要素)は
この `--slow--` 形の要素で、ゾーンの行を消すと 0 になった。

## 考察

- **ゾーンの行はテンションの差を作っている。** zone_line では「!」の数が slow → fast で 0.40 → 0.77 とほぼ倍になり、
  勢いの語は fast だけ 14.2% に跳ねる。no_zone_line では差が小さく(0.49 → 0.63)、勢いの語はほぼ出ない。
  キャラの口調(チアは元気・シズクは静か)は両案で保たれ、その中でゾーンの差が乗る。
- ただし見本 1 回分では差は目立たない(シズクの fast がまだ穏やか、など)。差は集計で見えるくらいの強さ。
- **代わりに、ゾーン名の漏れが 9.7% のバケットで起きている。** `-slow--` だけの文がプールに入ると、
  そのまま応援として表示・読み上げされる。これは「ゾーンの適合」とは別の、現行プロンプトの欠陥。
- 契約違反は variant がわずかに悪い(30 字超過 2.8 → 5.1%、失敗 0.8 → 1.1%)。中止条件の「明らかな悪化」に
  当たるかは判断が分かれる幅。30 字超過は層 3 が切り詰めるので、プールに入る文は 30 字以内に収まる。
- レイテンシは行を消したほうが 0.45 秒/バケット遅い。プロンプトが短いのに遅いのは、文がやや長くなった分と見られる。
- **baseline の値は論点 0026 の baseline と全指標で一致した**(レイテンシを除く)。同じシード・同じプロンプトで
  同じ出力が返っており、計測が再現できている。
- 考えられる次の手:ゾーンの行を残したまま、ゾーン名を英語のラベルでなく日本語で書く
  (例「打つのが遅いとき=寄り添う / …」)案を別の論点で測る。漏れを消しつつ、テンションの差を保てるかを見る。
