# 論点 0020: プール・wav の生成と永続化

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/pool-generation.md`**

## 何を決めるか

メッセージプールと音声の一括生成をいつ・どう走らせ、どこに置き、中断・再開をどう扱うか。
生成物で応援が発動するまでを含む。

## 決定

- 生成は**保存とは別の操作**として明示的に起動する。進捗を表示し、**中断できる**。
- 生成物は `{userData}` 配下に永続化し(`pool.json` と wav)、**起動時に読み込んで発動へ紐付ける**。
- 中断・失敗しても**それまでの生成物は捨てない**(再開できる)。
- プールが無い / バケットが欠けている状態でも応援は出る(baseline 定型文。論点 0013 のフォールバック)。
- 生成は文言 → 音声の順で行い、音声だけ失敗した場合はテキストのみで応援する。

## 理由

一括生成は数分かかりうる処理で、待たせる以上は「今どこまで進んだか」と「やめられること」が要る。
また生成が完了していない状態でも応援が動くことは、論点 0007 の「日常体験はゼロ依存」を守るために必要。

## 却下した案

- 生成完了までキャラを使えなくする — 生成失敗時にアプリが無価値になるため却下。
- 生成物をアプリ配下(インストール先)に置く — 権限と更新で壊れるため却下(`{userData}` に置く)。
