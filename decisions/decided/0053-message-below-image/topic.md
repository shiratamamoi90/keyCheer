# 論点 0053: キャラの窓 — セリフを絵の下に出し、吹き出しの大きさに上限を置き、セリフを出すかを設定にする

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/popup.md`**(S0053_01〜06。S0052_08 を欠番にし、S0017_01・S0036_24 に例外を足す)・**`docs/data-model.md`**(設定項目 popup.shouldShowMessage と既定値。S0053_07)・**`docs/main-window.md`**(設定画面での切り替え。S0053_08・09)

## 何を決めるか

Windows 実機で論点 0052 の実装を確かめた人間の指摘(2026-11-20。セリフが出ることは確認できた):

1. セリフは**絵の下**に出す(論点 0052 の決定 1「絵のすぐ上」を置き換える)。
2. セリフの吹き出しの大きさは、**縦は絵の 3 分の 1、横は絵の 1.5 倍まで**を許す。
   絵は 128x192(S0052_01)なので、吹き出しは**縦 64 × 横 192 まで**。
3. セリフを出すかどうかを**設定で変えられる**ようにする。

決定的(配置と上限は数値で受け入れ条件を書ける。設定は真偽値で、既定値・検証・反映を書ける)。
論点 0052 は決定済みなので書き換えず、この論点で決定 1 を置き換える(@.claude/rules/decision-rules.md「記録の不変性」)。

## 案

### 1・2 配置と大きさ(人間の指示どおり。下の `[要確認]` だけが残る)

- 絵の下端のすぐ下に、左右中央でセリフの吹き出しを置く。吹き出しは横 192・縦 64 を超えない。
- 窓の幅は吹き出しの最大幅(192)に合わせて狭める(今は 240)。窓の高さは 絵 192 + 隙間 + 64。
- 30 字(S0024 の上限)を縦 64 に収めるには、文字の大きさがおよそ 14px・3 行になる(1 行 12 字前後)。

### 3 セリフを出すかの設定

| | 案A:`popup.shouldShowMessage`(既定 true)を設定画面に出す | 案B:設定ファイルだけ(画面に出さない) |
| --- | --- | --- |
| 変え方 | 設定画面の「常時表示」の隣に切り替えを置く(S0036_29 と同じ形) | 手で JSON を書き換える |
| 反映 | 再起動しなくても次の応援から効く | 起動し直したとき |
| 手数 | 画面の項目が 1 つ増える | 利用者が触れない |

## 決定の前の考え(記録)

エージェントの考え(判断は人間):3 は案A。常時表示の切り替え(S0036_29)と同じ置き場・同じ反映のしかたにすると、
新しい仕組みを足さずに済む。

人間に確かめた点(2026-11-20。どれもエージェントの考えのとおりに決まった):

1. **30 字のセリフが縦 64 × 横 192 に収まらないとき**(フォントの違いなどで 4 行になる):
   - 案a:文字を小さくして収める
   - 案b:はみ出した分を切る(末尾を「…」にする)
   - 案c:上限を超えて広げる(上限を守らない)
   - エージェントの考え:案a。セリフが欠けると意味が変わる。
2. **セリフを出さない設定のとき、音声は鳴らすか。** エージェントの考え:鳴らす(設定の名前どおり、消すのはセリフの表示だけ)。
3. **セリフを出さない設定で、かつ常時表示を切っているとき**:今は応援の発動で窓を出し、セリフ(と音声)だけを出す(S0036_24)。
   両方切ると、窓に出すものが無い。
   - 案a:窓を出さず、音声だけ鳴らす
   - 案b:両方を切る組み合わせを設定画面で選べないようにする
   - エージェントの考え:案a。窓を出さないのは、出すものが無いことからそのまま決まる。
4. **隙間(絵の下端と吹き出しのあいだ)**:論点 0052 と同じく 0〜8 の「すぐ下」でよいか。

## 決定

人間の判断(2026-11-20)。論点 0052 の決定 1(セリフは絵のすぐ上)を置き換える。

1. **セリフは絵の下に出す。** 絵の下端のすぐ下(隙間 8 以下。論点 0052 と同じ「すぐ」)に、左右中央で置く。
   絵を動かしても、絵とセリフの並びは変わらない。窓は画面からはみ出さない(S0052_02 / S0052_07 のまま)。
2. **セリフの吹き出しは、縦は絵の 3 分の 1、横は絵の 1.5 倍を超えない**(絵 128x192 に対して縦 64 × 横 192)。
3. **収まらないときは文字を小さくして収める。** セリフは欠けさせない(切らない・上限を超えて広げない)。
4. **セリフを出すかを設定 `popup.shouldShowMessage`(既定 `true`)にする。** 設定画面の「常時表示」の隣で切り替え、
   再起動しなくても次の応援から効く。検証・既定値の扱いは `popup.shouldAlwaysShow` と同じ。
5. **セリフを出さない設定でも、音声は鳴らす。** 消すのはセリフの表示だけ。
6. **セリフを出さず、常時表示も切っているときは、応援の発動で窓を出さず、音声だけ鳴らす。**

## 理由

- 絵の下にセリフを置く・吹き出しの上限は、Windows 実機で見た人間の判断。
- 文字を小さくするのは、セリフが欠けると意味が変わるため。30 字(S0024)は縦 64 × 横 192 におよそ 14px・3 行で収まる。
- 設定の名前どおり、消すのはセリフの表示だけにする(音声は別の振る舞い)。
- 両方切ったときに窓を出さないのは、出すものが無いことからそのまま決まる。選べない組み合わせを作るより、組み合わせの規則が少ない。
- 設定画面に出すのは、常時表示の切り替え(S0036_29)と同じ置き場・同じ反映のしかたで済むため。

## 却下した案

- セリフを絵の上に出す(論点 0052 の決定 1)— 実機を見た人間が、絵の下を選んだ。
- 収まらないとき末尾を「…」にして切る — セリフが欠けると意味が変わる。
- 収まらないとき上限を超えて広げる — 人間が決めた上限を守らない。
- セリフを出さない設定で音声も止める — 設定の名前と振る舞いがずれる。音声を止めたければ別の設定にする。
- 両方を切る組み合わせを選べないようにする — 画面の規則が増える。窓を出さないだけで成り立つ。
- 設定ファイルだけで変える(画面に出さない)— 利用者が触れない。常時表示と同じく画面に出す。

## 決まらなかったこと(次の論点へ)

- 文字を小さくする下限(フォントによっては 3 行に収まらないとき、どこまで小さくするか)は、実装のときの見た目で決める
  (30 字の上限があるので、読めないほど小さくはならない見込み)。困ったら論点を開く。
- 音声を鳴らすかの設定は設けていない。必要になったら論点を開く。
