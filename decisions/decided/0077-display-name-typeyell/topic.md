# 論点 0077: 利用者に見える名前を TypeYell(タイプエール)にし、アイコンを差し替えられるようにする

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `README.md`**(利用者に見える名前。プロジェクトの名前との関係は `DEVELOPMENT.md` にも書く)

## 何を決めるか

人間の指示(2026-11-25):「keyCheer の名前を変える。ちゃんとアプリっぽいものに。アイコンも変える。アイコン用の画像はこちらで作成する」。
人間が選んだ:名前は **TypeYell(タイプエール)**。範囲は「見える名前だけにしつつ、プロジェクトとしての名前は keyCheer とする。文書にも記載」。

## 案

| | 案A:見える名前だけ変える | 案B:すべて変える |
| --- | --- | --- |
| データの置き場 | `%APPDATA%\keycheer` のまま | 移す仕組みが要る |
| リポジトリ・npm の名前・内部の識別子 | keyCheer / keycheer のまま | 変わる |

## 決定

人間が選んだ(2026-11-25):**案A**。1〜2 は人間の指示、3〜6 はエージェントが補い、人間が承認した(2026-11-25)。

1. 利用者に見える名前は **TypeYell**(読みは「タイプエール」)。窓の題名・トレイ・インストーラ(名前・ショートカット・アプリと機能の表示)・README の名前に使う。
2. プロジェクトの名前は keyCheer のまま(リポジトリ・npm の名前 `keycheer`・IPC の名前・ログの先頭・文書の中の開発の話)。文書に「アプリの名前は TypeYell、プロジェクトの名前は keyCheer」と書く。
3. データの置き場は `{userData}` = `%APPDATA%\keycheer` のまま変えない(今のキャラクター・設定・重みをそのまま使う)。Electron は表示名から置き場を決めるので、起動の最初に置き場を固定する。
4. アンインストール(S0048_13)と、インストーラからの削除(S0075_02)で消える置き場も同じ `%APPDATA%\keycheer`。
5. アイコンは人間が作る 1 枚の画像(512×512 以上の正方形の PNG。透過可)から、アプリ・インストーラ・トレイのアイコンを作る。置き場は `assets/icon.png`。画像が届くまでは今のまま(Electron の既定)。
6. 前の版(インストーラで入れた keycheer)は、更新のインストールでそのまま置き換わる(登録情報の鍵はアプリの id から決まり、名前を変えても変わらない)。

## 理由

- 3:置き場を変えると、今のデータを移す仕組みと、その失敗の扱いが要る。見える名前を変えるだけなら要らない。
- 5:Windows のアイコン(.ico)は electron-builder が 1 枚の PNG から作る。トレイは同じ画像を縮小して使う。

## 却下した案

- 案B — データを移す仕組みが要り、プロジェクトの名前は keyCheer のまま残す指示と合わない。

## 決まらなかったこと(次の論点へ)

- なし。
