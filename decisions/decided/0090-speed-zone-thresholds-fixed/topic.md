# 論点 0090: 速度ゾーンの境目を、測らずに今の値で確定する

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/speed-zone.md`**

## 何を決めるか

速度ゾーンの境目(slow 0〜99 / normal 100〜249 / fast 250〜 KPM)は、`docs/speed-zone.md` で「仮置き、利用実態で調整」「β版で実測して確定する([要確認])」のまま残っていた。
測って決めるか、今の値で確定するかを決める。

## 案

| | 案A:測らずに今の値で確定する | 案B:打つ速さの分布を測って決める |
|---|---|---|
| 測るもの | なし | 利用者の 1 分あたりの打鍵数の分布(回数だけ) |
| 手間 | なし | 計測用のスクリプトを作り、しばらく使って測る(アプリは回数以外を記録しない — 論点 0080 / 0081) |
| 種別 | 人の判断で値を固定する(決定的) | 計測で決める(非決定的) |

## 現在の考え

エージェントは、起動の上限だけ測り、境目は使い続けてから決める案を出した。人間は両方とも測らずに確定することを選んだ(2026-11-27)。

## 決定

**案A。境目は今の値で確定する**(人間の決定 2026-11-27):slow 0〜99、normal 100〜249、fast 250〜(KPM。下限を含む — S0012_06)。
`docs/speed-zone.md` の「仮置き」と `[要確認]` を外す。値もコード(`src/core/speedZone.ts`)も変えない。

## 理由

- 人間の判断。測るための仕組み(計測用のスクリプト・しばらく使う期間)に見合う差が見込めない。
- 境目を変えたくなったら、そのときに新しい論点で変えればよい(値は `src/core/speedZone.ts` の定数 2 つ)。

## 却下した案

- 案B(分布を測って決める)— 人間が採らなかった。

## 決まらなかったこと(次の論点へ)

- なし。
