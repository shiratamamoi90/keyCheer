# 論点 0061: 保存画面と生成画面を 1 つの「キャラクター」画面にまとめる

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/main-window.md`**

## 何を決めるか

人間の指示(2026-11-21):**保存と生成の画面をまとめてよい。保存をベースにして生成ボタンを足す。
生成した後、キャラクターの入力の枠の下に、成功や失敗の結果を出す。**

決めること:まとめた画面の名前、生成ボタンを押せる条件、進捗と結果を出す場所、最初に出す画面。

## 案

### 生成ボタンを押せる条件

| | 案A:保存してから生成する | 案B:保存済みのときだけ押せる |
| --- | --- | --- |
| 新規の入力・書き換え中 | 押すと保存し、続けて生成する | 押せない。先に「保存」を押す |
| 何を生成するかの分かりやすさ | 保存と生成が 1 回で起きる | 保存したものだけが生成される(論点 0033 の S0033_09 と同じ考え) |

### 画面の名前

キャラクター / 作成 / 保存(今のまま)。

## 決定

1. **保存画面と生成画面を 1 つにまとめ、「キャラクター」画面とする。** タブは「キャラクター」「切り替え」「設定」の 3 つ。
2. **画面は保存画面をもとにし、入力の枠に「生成」ボタンを足す。** 生成するのは、一覧で選んでいる保存済みのキャラクター。
3. **生成ボタンは、保存済みのキャラクターを選んでいて、入力が保存した内容と同じときだけ押せる**(案B)。新規の入力・書き換え中・生成中は押せない。
4. **進捗・中断・結果(成功・失敗の理由・作った 3 枚)は、入力の枠の下に出す。** 進捗と中断はこの画面だけに出す(S0033_08 の考えのまま)。
5. 最初に出す画面:キャラクターが 0 件、またはプールのあるものが無ければキャラクター画面。プールのあるものがあれば切り替え画面(今のまま)。
6. 作り直しの確認(論点 0038)・生成中の示し方(S0033_07)・画像だけ作り直す(論点 0050)は、生成画面をキャラクター画面に読み替えるだけで変えない。

- 廃止:S0033_01(4 つの画面)・S0033_09(生成画面で選べるのは保存済みだけ)・S0050_02(生成画面に 3 枚)(欠番)。
- 新しい要件:S0061_01〜06(`docs/main-window.md`)。
- そのほかのシナリオの「保存画面」「生成画面」「生成タブ」は「キャラクター画面」「キャラクタータブ」に読み替える(意味は変えない)。

人間の判断(2026-11-21):生成ボタンは案B、名前は「キャラクター」。

## 理由

- 人間の指示。保存してから生成するまでに画面を移る手間が無くなる。
- 押せる条件を「保存済みで入力が保存した内容と同じ」にすると、画面に見えている内容と生成に使う内容が食い違わない
  (書き換え中に押せると、保存前の古い内容で生成される)。

## 却下した案

- **保存してから生成する(1 回で両方)** — 人間が「保存済みのときだけ押せる」を選んだ。
- **名前を「作成」「保存」にする** — 人間が「キャラクター」を選んだ。

## 決まらなかったこと(次の論点へ)

- なし。
