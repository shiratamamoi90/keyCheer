# 論点 0003: ローカル TTS に何を使うか

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/integrations.md`**

## 何を決めるか

キャラが声で応援する体験のため、高品質な日本語 TTS をローカルで使いたい。

## 決定

VOICEVOX Engine をローカルで使用(HTTP :50021)。

## 理由

- 利点: 高品質な日本語音声、HTTP API で連携が容易、キャラ性を出せる話者が豊富。
- 欠点 / トレードオフ: 別途インストール or 同梱(~200MB)が必要。未起動時はテキストのみ表示にフォールバック。

## 案(採らなかったものは却下理由付きで残す)

- OS 標準 TTS: 導入は楽だがキャラ性・品質が不足。
