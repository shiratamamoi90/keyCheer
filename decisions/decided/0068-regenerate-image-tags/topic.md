# 論点 0068: 画像だけ作り直すときに画像タグも作り直す

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/pool-generation.md`**(S0050_09・S0050_12・S0050_13 を置き換える)

## 何を決めるか

人間の指示(2026-11-25):「画像を作り直す処理について、ノーマルも含めてすべての画像を作り直す」。確かめたところ、
**画像タグ(見た目・表情)も作り直したい**、という意味だった。

今は論点 0050 の決定 3 で、「画像だけ作り直す」は**記録した画像タグをそのまま使い**、シードだけ 1 増やして 3 枚を作る(S0050_09)。
そのため髪・服など見た目の語は変わらず、同じ人物の描き直しにしかならない。これを、画像タグも出させ直して 3 枚を作る形に変える。

決めること:

1. 画像タグを毎回出させ直すか、今の「記録の画像タグを使う」を残して選べるようにするか
2. 画像タグの要求に渡すシード(同じシードだとテキストモデルが同じ画像タグを返しやすい)
3. 記録(画像タグとシード)の扱いと、S0050_13(同じ画像タグとシードなら同じ絵)の扱い

## 案

### 1. 画像タグを出させ直すか

| | 案A:毎回出させ直す | 案B:操作を 2 つにして選ばせる(画像タグも / 絵だけ) |
| --- | --- | --- |
| 操作 | 今の「画像だけ作り直す」1 つのまま | 2 つになる |
| 人物の見た目 | 毎回変わりうる | 選べる |
| 人間の指示との合い方 | そのまま | 足している(指示に無い) |

### 2. 画像タグの要求に渡すシード

| | 案X:画像と同じ s + 1 を渡す | 案Y:画像タグだけ既定のシードのまま |
| --- | --- | --- |
| 画像タグが変わるか | 作り直すたびに変わる | 同じシードなので、同じ画像タグが返りやすい(作り直す意味が薄い) |
| 再現(同じ記録から同じ結果) | 同じ s から同じ要求になる | 同じ |

## 現在の考え

**案A + 案X**。

- 「画像だけ作り直す」では、3 枚それぞれの画像タグを毎回出させ直す(待機画像は見た目、応援種別の画像は表情。S0049_01・S0062_05 の要求のまま)。
  画像タグの要求にも、画像にも、記録のシード + 1(記録が無ければ既定のシード + 1)を渡す。
- 3 枚と 3 つの画像タグがそろったら、画像を置き換え、**新しい画像タグとシードを記録する**(記録は次の作り直しのシードを決めるのに使う)。
  そろわなければ(画像タグの形式違反・画像の失敗・中断)、前の 3 枚と記録を残す(S0050_11 のまま)。
- 記録が無いキャラクターの扱い(S0050_12)は、記録があるときと同じ流れになるので 1 つにまとめる。
- S0050_13(同じ画像タグとシードなら同じ絵になる)は、作り直しが記録の画像タグを使わなくなるので欠番にする。
  sd.cpp の同じシードで同じ絵になることは S0016_29 が縛っている。テキストモデルの出力は同じシードでも揺れることがある(論点 0067 の `result.md`)。
- 生成(全体)は今のまま(既定のシード・画像タグを出させて記録)。

決定済み(下)。

## 決定

人間が承認した(2026-11-25):**案A + 案X**(上の「現在の考え」のとおり)。論点 0050 の決定 3 のうち「記録した画像タグをそのまま使う」を置き換える。
`docs/pool-generation.md` の S0050_09・S0050_12・S0050_13 を欠番にし、S0068_01〜04 に置き換えた。

## 理由

- 人間の指示は「すべての画像を作り直す」で、見た目の画像タグが変わらないと同じ人物の描き直しにしかならない。
- 画像タグの要求にも s + 1 を渡すのは、同じシードだとテキストモデルが同じ画像タグを返しやすく、作り直す意味が薄れるため。
- 記録の有無で流れを分ける理由が無くなったので、S0050_12 を 1 つにまとめた。

## 却下した案

- 案B(操作を 2 つにして選ばせる)— 人間の指示に無い操作を足すことになる。
- 案Y(画像タグは既定のシードのまま)— 同じ画像タグが返りやすく、作り直す意味が薄い。

## 決まらなかったこと(次の論点へ)

- なし。
