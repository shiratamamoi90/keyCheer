# 論点 0078: ローカルのランタイムの接続先を 127.0.0.1 にそろえる

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/data-model.md`**(S0078_01〜04)

## 何を決めるか

設定の既定の接続先は `http://localhost:11434` / `http://localhost:50021`、同梱ランタイムは `127.0.0.1` だけで待ち受ける(S0034_12)。
Windows では `localhost` が IPv6 の `::1` を先に引くことがあり、`127.0.0.1` だけで待ち受ける同梱ランタイムに繋がらないおそれがある。
接続先の値はコードの数か所に書き分けられている(リファクタリングの指示 2026-11-25「名前・接続先の直書きを 1 か所に」)。

## 案

| | 案A:既定値を 127.0.0.1 にし、旧既定値だけ移す | 案B:既定値だけ変える |
| --- | --- | --- |
| 今の設定 | 旧既定値のままなら新しい値になる | 手で直す |

## 決定

エージェントの案を人間が承認した(2026-11-25):**案A**。

1. 既定値を `http://127.0.0.1:11434` / `http://127.0.0.1:50021` にする。
2. 保存値が旧既定値(`http://localhost:11434` / `http://localhost:50021`)と完全に同じときだけ、読み込みで新しい既定値に移して保存し直す(論点 0028 / 0069 と同じ考え)。通知は出さない。それ以外の値は変えない。
3. 接続先の値(ホスト・ポート)はコードの 1 か所に置き、設定の既定値・同梱ランタイム・話者一覧の取得が同じものを読む。

## 理由

- 同梱ランタイムの待ち受け(S0034_12)と同じ宛先にし、名前の引き方で繋がらない事故を無くす。
- 旧既定値のままの人は選んだのではなく変えていないだけなので移す。

## 却下した案

- 案B — 今の環境は設定を手で直さないと変わらない。

## 決まらなかったこと(次の論点へ)

- なし。
