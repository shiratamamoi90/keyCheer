# 論点 0072: インストーラの重みの照合とコピーを、アプリの補助モードで行う

- **種別: 決定的**
- **状態: 決定済み**
- **反映先: `docs/model-weights.md`**(音声モデルは別ファイルにしない旨。満たすことは S0055_01〜06 のまま)

## 何を決めるか

論点 0055 はインストーラが重みの別ファイルを sha256 で照合して置き場にコピーすると決めたが、何がそれを行うかは決めていない。
重みは 1 ファイル約 2 GB で、照合・空き容量の確認・コピー・失敗したときの後始末が要る。配布は GitHub の Releases(人間の確認 2026-11-25)。

## 案

| | 案A:アプリの補助モード | 案B:インストーラ(NSIS)自身 |
| --- | --- | --- |
| sha256 の計算 | Node の crypto | 外部プラグインが要る |
| テスト | vitest で縛れる | 縛れない |
| インストーラの仕事 | 補助モードを起動し、結果を示す | すべて |

## 決定

人間が選んだ(2026-11-25):**案A**。1 は人間の選択、2〜5 はエージェントが補い、人間が承認した(2026-11-25)。

1. インストーラはアプリを入れたあと、入れたアプリを補助モードで起動し、重みの照合・空き容量の確認・コピー(と論点 0073 の取り込み)を任せる。
2. 補助モードは窓もトレイもキーフックも出さず、終わったら終了する。結果(成功 / 足りないファイル名 / 一致しないファイル名 / 空き容量不足)を終了コードと標準出力で返し、インストーラはそれを示す。
3. 重みの一覧(ファイル名・置き先・sha256・大きさ)は 1 つの定義にまとめ、補助モードとアプリの照合(S0055_08 / S0059)が同じものを読む。
4. コピーは置き場の中の一時ファイルに書いてから名前を変える。失敗・中止のときは一時ファイルと、この回に置いた重みを消す(S0055_02 の「途中までコピーした重みは残さない」)。
5. 音声モデルは VOICEVOX ENGINE の配布物の中にあり、ENGINE と一緒にインストーラ本体に入る(`docs/model-weights.md` の表「同梱ランタイムの一部」)。重みの別ファイルにするのはテキストモデルと画像の重み 2 つ。

## 理由

- 数 GB の照合とコピーと後始末を、テストで縛れる所に置く。NSIS に sha256 のプラグインを足さずに済む。
- 2:インストーラの画面に足りないファイルの名前を出すため(S0055_02 / S0055_03)。
- 5:ENGINE は音声モデルを自分のフォルダから読み、置き場を変えると ENGINE の配布物の形を崩す。

## 却下した案

- 案B — 照合とコピーの失敗の扱いをテストで縛れず、sha256 の外部プラグインが要る。

## 決まらなかったこと(次の論点へ)

- インストーラ本体が 2 GiB(GitHub の Releases の上限・NSIS の制約)に収まるか。作る段で大きさを測る。
