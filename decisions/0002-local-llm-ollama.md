# ADR 0002: ローカルLLMに Ollama / モデルは gemma2:2b 推奨(2026-05)

## 文脈

応援メッセージを動的生成したいが、完全オフライン・通常ノートPC で動く必要がある。

## 決定

Ollama を使用。推奨モデルは軽量な gemma2:2b。

## 結果

- 利点: 短文生成なら軽量モデルで十分。レスポンスとリソースのバランスが良い。HTTP API で連携容易。
- 欠点 / トレードオフ: モデル取得(~1.6GB)が初回必要。未起動/未取得時はフォールバック(定型文)が要る。

## 比較した選択肢

- より大きなモデル: 品質は上がるがレイテンシ・リソースが応援用途に過剰。
