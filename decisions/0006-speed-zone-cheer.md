# ADR 0006: 打鍵速度を計測し、速度ゾーンで応援文言を切り替える(2026-05)

## 文脈

「沢山打った」だけでなく「集中して速く打った/のんびり打った」をキャラが認識して反応する方が体験が良い。
LLM に連続値を直接渡すと出力が不安定になる。

## 決定

- **アクティブ時間判定**: 最後のキー押下から **60 秒以内**を「入力中」とみなす(60秒以上空けばセッション終了)。
- **速度評価**: **直近1分のキー押下数(KPM: Keys Per Minute)**で判定。
- **速度ゾーン**: 3段階(`slow` / `normal` / `fast`)に丸め、Ollama プロンプトに含めて文言を切り替える。
- ゾーン閾値は仮置き(slow: <100, normal: 100-249, fast: >=250)、利用実態を見て調整。

## 結果

- 利点:
  - キャラが「今のテンション」に反応でき体験が良い。
  - 60 秒は離席/思考時間を自然に切り分ける定番値。
  - 離散3ゾーンに丸めることで LLM 出力が安定し、ゾーン別プリキャッシュも設計しやすい。
- 欠点 / トレードオフ:
  - 閾値はβ版で実測して確定する必要がある。

## 比較した選択肢

- 30 秒判定: 厳密すぎ、考え事の間も離席扱い。
- 5分平均 / セッション平均: スパイクで応援が変わる楽しさが失われる。
- 連続値(KPM そのもの)を LLM に渡す: 出力ぶれが大きくプリキャッシュ設計が難しい。
- 4段階(爆速ゾーン追加): milestone と組み合わせれば代替可能なので 3 段階で十分。

## 未確定事項 [要確認]

- ゾーン閾値の最終確定(β版で実測)。
- キーリピート(押しっぱなし)を1回と数えるか除外するか。
- 速度ゾーン別プリキャッシュの個数バランス。
