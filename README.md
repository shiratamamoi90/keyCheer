# KeyCheer ⌨️🎉

キー押下数・打鍵速度に応じて、自分で設定したキャラクターが音声とポップアップで応援してくれる
Windows デスクトップアプリ。応援はアプリ単体(オフライン)で完結する。

## これは何か

タイピング作業は成果が見えにくく、集中が続いた時間も「たくさん打った」実感も残らない。
KeyCheer は打鍵数と打鍵速度だけを見て、区切りのいいところで自分の作ったキャラクターが
声とポップアップで応援してくれる。**入力した内容は一切記録しないし、送信もしない**ので、
仕事中でも常駐させたままにできる。応援の文言と声はキャラを作るときにまとめて用意するので、
使っている間はネットワークにもローカルのサーバーにも一切繋がない。

## できること

- 設定した回数キーを押す・節目に到達すると応援が出る(間隔は設定可能。既定 50 キー)
- 打鍵速度(直近1分)に応じて応援の内容が変わる(のんびり / 普通 / 集中)
- キャラクターの名前・性格・声を自分で決められる。応援メッセージと音声はキャラ作成時に一括生成
- 生成はすべて自分の PC の中(Ollama / VOICEVOX / stable-diffusion.cpp)で行う。外部のサービスは使わない
- 時間帯(朝 / 昼 / 夕方 / 夜)に合わせた応援

**やらないこと(対応範囲外)**:入力内容の記録・分析、他アプリの監視、クラウド同期、
作業内容に応じたアドバイス。KeyCheer が見るのは「キーが押された回数と時刻」だけ。

## 動作環境

- Windows(10 以降)
- キャラ作成時のみ、生成手段の用意が必要
  - Ollama(`:11434`)と VOICEVOX ENGINE(`:50021`)
- 応援を出すだけなら追加のサービス・アカウントは不要

> **現状の制限**:ローカル生成用のランタイム(Ollama / VOICEVOX)はまだ同梱していないため、
> キャラを作るときだけ各自で起動しておく必要がある。未起動でもアプリは落ちず、
> 同梱の定型文で応援する。

## インストール

配布インストーラは準備中。現時点ではソースから起動する。

```bash
npm install
npm run build
npm run dev
```

## 使い方

起動するとタスクトレイに常駐し、キー入力の回数を数え始める。
キャラクターを作っていない状態でも、同梱の定型文で応援が出る。

1. **キャラクターを作る** — 起動時に開くメインウィンドウの「キャラクター」画面で、名前・性格・声(話者)を入力して保存する。
2. **応援を用意する** — 同じ画面の生成ボタンを押すと、応援メッセージ・音声・キャラクターの画像がまとめて作られる(数分かかる)。
   生成ボタンは、保存したキャラクターを選んでいて、入力を書き換えていないときだけ押せる。
   進捗と結果は入力の枠の下に出て、途中でやめることもできる。画像が作れなかったときは、結果にその理由が出る
   (画像が無くても、応援は文言と声で出る)。
3. **あとは打つだけ** — 設定した回数キーを押すと、作ったキャラが声とポップアップで応援してくれる。

### キャラクターの画像

画像は 1 キャラクターにつき 3 枚(ふだんの絵・通常の応援の絵・節目の応援の絵)。背景は透明で、
ふだんの絵が画面の隅に出続け、応援が出ている間だけその応援の絵に替わる(設定の「常時表示」で切れる)。
セリフは絵のすぐ下に出る。設定の「セリフを表示する」を外すと、セリフを出さずに声だけ鳴る。
絵はつかんでドラッグすれば動かせ、動かした位置は次の起動でも使われる(絵の外のクリックはその下のアプリに通る)。

画像を作るには、画像生成のモデルの重み(約 2.1 GB)が要る。重みは配布物に入っていて、インストーラが置く
(アプリが重みを取りに行く通信はしない)。置く前に、ライセンスと利用の制限が表示され、同意が求められる。
同梱物のライセンスはインストーラの画面で示す(アプリの中には出さない)。重みが欠けていると、画像なしで生成が終わる。

重みは [Counterfeit V3.0](https://huggingface.co/gsdf/Counterfeit-V3.0)(CreativeML OpenRAIL-M)と
[LCM LoRA](https://huggingface.co/latent-consistency/lcm-lora-sdv1-5)(OpenRAIL++)。

> **現状の制限**:インストーラはまだ無い。開発版では重みを `{userData}/weights/image/` に手で置く。
画像の生成は CPU で行い、3 枚で数分かかる。

声は、四国めたん・春日部つむぎ・雨晴はう・玄野武宏(いずれも VOICEVOX のノーマル)の 4 つから選ぶ。

### 応援の頻度を変える

メインウィンドウの「設定」画面の「応援」で変える。値を入れて欄から離れる(または Enter)とすぐ保存され、次の打鍵から効く。
範囲の外の値は入れられない(確定したときに範囲の端の値になる)。

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| 通常応援の間隔 | `50` キー | この回数打つごとに応援が出る(1〜10000) |
| 節目(マイルストーン) | `250` キー | 累計がこの数の倍数になるたびに特別な応援が出る(通常応援の間隔より大きい値〜100000。「節目の応援を出す」を切ると出ない) |
| 入力中とみなす秒数 | `60` 秒 | 最後の打鍵からこの秒数が過ぎたら区切りとみなす(5〜600) |

> 打鍵速度の判定に使う「直近1分」は設定では変わらない(「分あたりの打鍵数」の意味を保つため)。

## 困ったときは

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 応援は出るが声が鳴らない | 音声がまだ生成されていない | メインウィンドウの「キャラクター」画面で生成する |
| 応援の文言がいつも同じ | プールが未生成で同梱の定型文が使われている | 同上 |
| キャラクターの画像が出ない | 画像が作られていない(完了の表示に理由が出る)。または「常時表示」を切っている | 重みを入れ直してから(インストーラ。開発版は手で置く)、生成し直す |
| キャラ作成で「生成できない」と出る | Ollama / VOICEVOX が起動していない | 両方を起動してから再試行する |
| 応援がまったく出ない | 通常応援の間隔が大きすぎる | 「設定」画面で通常応援の間隔を小さくする |

解決しない場合は issue で報告してほしい。**入力内容は一切記録していない**ため、
報告には「OS のバージョン」「何をしたとき」「画面に出たメッセージ」を添えてもらえると助かる。

## プライバシー

- 数えるのは**キーが押された回数と時刻だけ**。どのキーを押したか・何を入力したかは保存も送信もしない。
- 打鍵数・速度・統計・応援の発動は**外部に一切送信しない**(ローカルのサーバーにも繋がない)。
- キャラ作成の生成も PC の中だけで行い、性格などの入力を外部へ送らない。
