# KeyCheer ⌨️🎉

キー押下数・打鍵速度に応じて、自分で設定したキャラクターが音声とポップアップで応援してくれる
Windows デスクトップアプリ。応援はアプリ単体(オフライン)で完結する。

## これは何か

タイピング作業は成果が見えにくく、集中が続いた時間も「たくさん打った」実感も残らない。
KeyCheer は打鍵数と打鍵速度だけを見て、区切りのいいところで自分の作ったキャラクターが
声とポップアップで応援してくれる。**入力した内容は一切記録しないし、送信もしない**ので、
仕事中でも常駐させたままにできる。応援の文言と声はキャラを作るときにまとめて用意するので、
使っている間はネットワークにもローカルのサーバーにも一切繋がない。

## できること

- 設定した回数キーを押す・節目に到達すると応援が出る(間隔は設定可能。既定 50 キー)
- 打鍵速度(直近1分)に応じて応援の内容が変わる(のんびり / 普通 / 集中)
- キャラクターの名前・性格・声を自分で決められる。応援メッセージと音声はキャラ作成時に一括生成
- 生成手段はローカル(Ollama / VOICEVOX / stable-diffusion.cpp)と
  外部 API(OpenAI / Anthropic / ElevenLabs / DALL·E / Stability AI)から選べる
- 時間帯(朝 / 昼 / 夕方 / 夜)に合わせた応援

**やらないこと(対応範囲外)**:入力内容の記録・分析、他アプリの監視、クラウド同期、
作業内容に応じたアドバイス。KeyCheer が見るのは「キーが押された回数と時刻」だけ。

## 動作環境

- Windows(10 以降)
- キャラ作成時のみ、生成手段の用意が必要
  - ローカルで作る場合:Ollama(`:11434`)と VOICEVOX ENGINE(`:50021`)
  - 外部 API で作る場合:各サービスの API キー
- 応援を出すだけなら追加のサービス・アカウントは不要

> **現状の制限**:ローカル生成用のランタイム(Ollama / VOICEVOX)はまだ同梱していないため、
> キャラを作るときだけ各自で起動しておく必要がある。未起動でもアプリは落ちず、
> 同梱の定型文で応援する。

## インストール

配布インストーラは準備中。現時点ではソースから起動する。

```bash
npm install
npm run build
npm run dev
```

## 使い方

起動するとタスクトレイに常駐し、キー入力の回数を数え始める。
キャラクターを作っていない状態でも、同梱の定型文で応援が出る。

1. **キャラクターを作る** — 起動時に開くメインウィンドウで、名前・性格・声(話者)を入力して保存する。
2. **応援を用意する** — 「生成」を押すと、応援メッセージと音声がまとめて作られる(数分かかる)。
   進捗が表示され、途中でやめることもできる。
3. **あとは打つだけ** — 設定した回数キーを押すと、作ったキャラが声とポップアップで応援してくれる。

### 応援の頻度を変える

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| 通常応援の間隔 | `50` キー | この回数打つごとに応援が出る(1〜10000) |
| 節目(マイルストーン) | 一覧で指定 | 到達したときに特別な応援が出る(空にすると無効) |
| 入力中とみなす秒数 | `60` 秒 | 最後の打鍵からこの秒数が過ぎたら区切りとみなす(5〜600) |

> 打鍵速度の判定に使う「直近1分」は設定では変わらない(「分あたりの打鍵数」の意味を保つため)。

### 外部 API を使う場合

外部サービスで応援メッセージや声を作ることもできる。**その場合だけ**、入力した性格などの
テキストが選んだサービスへ送られる。送信の前に必ず内容を提示する同意画面が出る。
API キーは Windows の資格情報マネージャー(Electron `safeStorage`)に保存され、
設定ファイルには平文で書かれない。送信した記録は `audit.log.json` に残る。

## 困ったときは

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 応援は出るが声が鳴らない | 音声がまだ生成されていない | メインウィンドウから「生成」を実行する |
| 応援の文言がいつも同じ | プールが未生成で同梱の定型文が使われている | 同上 |
| キャラ作成で「生成できない」と出る | Ollama / VOICEVOX が起動していない | 両方を起動してから再試行する(または外部 API を選ぶ) |
| 外部 API でエラーになる | API キーが未設定 / 期限切れ / 残高不足 | キーを確認する。**自動でローカルに切り替わることはない**(意図しない送信を防ぐため) |
| 応援がまったく出ない | 通常応援の間隔が大きすぎる | 設定で間隔を小さくする |

解決しない場合は issue で報告してほしい。**入力内容は一切記録していない**ため、
報告には「OS のバージョン」「何をしたとき」「画面に出たメッセージ」を添えてもらえると助かる。

## プライバシー

- 数えるのは**キーが押された回数と時刻だけ**。どのキーを押したか・何を入力したかは保存も送信もしない。
- 打鍵数・速度・統計・応援の発動は**外部に一切送信しない**(ローカルのサーバーにも繋がない)。
- 外部への送信が起きるのは、キャラ作成時に自分で外部サービスを選び、同意した場合だけ。
