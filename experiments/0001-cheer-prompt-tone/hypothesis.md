# 仮説

Ollama プロンプトに速度ゾーン(slow/normal/fast)と当日アクティブ時間を明示的に含めると、
応援メッセージの「状況適合度」と「多様性」が baseline(ゾーンを渡さない現行プロンプト)より上がる。

## 測り方

- 評価データ: 代表的な状況サンプル 30 件(count / type / timeOfDay / kpm / zone の組み合わせ)
- モデル: gemma2:2b(固定)、temperature 固定、seed 固定
- 試行: 各サンプル 5 生成 = 150 メッセージ
- 指標:
  - 状況適合度(人手 1〜5 スコアの平均)
  - 多様性(同一サンプル内のユニーク率)
  - 1メッセージあたり生成レイテンシ(ms)— プリキャッシュ予算の確認用
  - 契約違反率(30文字超過・空・複数文)

## 比較対象

- baseline: baselines/ の「定型文ジェネレータ」と、ゾーン情報を渡さない現行プロンプト

## 中止条件

- 平均レイテンシがプリキャッシュ予算を超え、かつ補充が追いつかない見込みなら中止し現行プロンプトに戻す。
- 契約違反率が baseline より悪化したら中止(品質以前の問題)。
