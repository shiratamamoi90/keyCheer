---
name: validate
description: spec とテストの整合を検査する。OpenSpec の validate --strict 相当を自前で行う。
---

進行中および確定済みの仕様を検査して、欠落を報告する。

検査項目:

1. changes/_/spec.md と specs/_.md の各シナリオに GIVEN / WHEN / THEN が揃っているか。
2. 各シナリオに対応するテストが tests/ に存在するか(シナリオ名 ↔ テストメソッド名で照合)。
3. 正常系だけで異常系・境界シナリオが欠けていないか。
4. `[要確認]` タグが未解決のまま実装に進んでいないか。
5. result.md にシードや依存固定の記述なしに数値が書かれていないか。

各違反を「ファイル:該当箇所:理由」の形で列挙する。問題なければ「整合OK」と報告する。
可能ならこの検査を scripts/validate に切り出し、CI / Stop フックから呼べる形にする提案を添える。
