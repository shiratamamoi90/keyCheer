# 要件: モデル重みの同梱

ローカルで生成するためのモデル重みを、すべて配布物に入れる(論点 0055)。**重みの取得(通信)はアプリにもインストーラにも無い。**
配布物は、インストーラ本体と**重みの別ファイル**を同じフォルダに置いたもの。インストーラは別ファイルの重みを照合して置き場にコピーする。
重みが欠けた・壊れたときは、インストーラで入れ直す。利用者にコマンドを打たせない(論点 0010)。

> 論点 0042(アプリの中の取得)と論点 0048(インストール中の取得)は論点 0055 で置き換えた。
> S0042_01〜07・S0042_09・S0042_10・S0042_12・S0042_13・S0048_01〜12 は欠番(S0042_08 / S0042_11 は論点 0054 で欠番)。

同梱する重み(どれも必須。選んで外せない):

| 重み | 使うプロバイダー | 欠けているとき(壊れたときだけ) |
| --- | --- | --- |
| テキストモデル(sarashina2.2-3b-instruct の q4_K_M の GGUF 1 ファイル。論点 0027 / 0030 / 0059) | `local-ollama` | 生成を始められない(入れ直しを案内する) |
| 画像の重み(ベースモデル + LCM LoRA。論点 0041) | `local-sdcpp` | 生成は始められ、画像なしで完了する |
| VOICEVOX の音声モデル(選べる話者の分。論点 0044) | `local-voicevox` | (論点 0034 の同梱ランタイムの一部) |

置き場は `{userData}/weights/`(画像の重みのファイル名は論点 0040)。テキストモデルは `{userData}/weights/text/sarashina2.2-3b-instruct-q4_K_M.gguf`(論点 0059。
sha256 は `decisions/decided/0059-text-model-bundle-form/config.yaml`)。案内や操作の見た目は仕様化しない。

画像の重みの出所(論点 0041。配布物に入れる版を固定する。sha256 は `decisions/decided/0041-image-base-model/config.yaml`):

| | リポジトリ | コミット | ファイル | サイズ |
| --- | --- | --- | --- | --- |
| ベースモデル | `gsdf/Counterfeit-V3.0` | `d8ce63b3eb8e9102e54b3fcc07f9cb7a28ef30fc` | `Counterfeit-V3.0_fix_fp16.safetensors` | 2034 MB |
| LCM LoRA | `latent-consistency/lcm-lora-sdv1-5` | `cf2fced511dbe7e26c8d1d397e728fbab875db4b` | `pytorch_lora_weights.safetensors` | 128 MB |

インストーラは重みを置く前に、画像の重みのライセンスへの同意を取る(`docs/licenses.md` S0047_02 / S0047_03)。

## インストール

### S0055_01 インストーラは重みの別ファイルを照合して置き場にコピーする

- GIVEN インストーラ本体と同じフォルダに、重みの別ファイルが揃っている。空き容量が足りる
- WHEN ライセンスへの同意をしてインストールを進める
- THEN テキストモデル・画像の重み・音声モデルが、sha256 の照合を通ったうえで置き場に置かれ、インストールが完了する。
  アプリを起動すると、重みが揃った状態として扱われる

### S0055_02 重みの別ファイルが無ければインストールを完了しない [異常系]

- GIVEN 重みの別ファイルのうち 1 つ以上が、インストーラと同じフォルダに無い
- WHEN インストールを進める
- THEN 足りないファイルの名前を示し、インストールを完了しない。途中までコピーした重みは残さない

### S0055_03 照合が通らなければインストールを完了しない [異常系]

- GIVEN 重みの別ファイルの sha256 が、決められた値と一致しない
- WHEN インストールを進める
- THEN 一致しなかったファイルの名前を示し、インストールを完了しない。一致しなかった重みは置き場に置かない

### S0055_04 空き容量が足りなければコピーを始めない [異常系]

- GIVEN 置き場の空き容量が、置く重みの合計より小さい
- WHEN インストールを進める
- THEN コピーを始めず、空き容量が足りない旨を示して、インストールを完了しない

### S0055_05 インストールで通信しない [否定]

- GIVEN インストーラ
- WHEN 起動から完了(または中止)まで進める
- THEN 通信は**発生しない**(重みは同じフォルダの別ファイルから取る)

### S0055_06 更新のインストールでは照合の通る重みをコピーし直さない [境界]

- GIVEN 置き場に、sha256 が決められた値と一致する重みがある機械
- WHEN 新しい版のインストーラを実行する
- THEN その重みはコピーし直さず、そのまま残す。一致しない・無い重みだけを別ファイルから置く

## アプリの中

### S0055_07 アプリは重みの取得の通信をしない [否定]

- GIVEN 重みが揃っている、または欠けている
- WHEN アプリを起動する、メインウィンドウを表示する、生成を始める
- THEN 重みを取りに行く通信は**発生せず**、重みを取得する操作も出さない

### S0055_08 テキストモデルが欠けていれば生成を始めず、入れ直しを案内する [異常系]

- GIVEN 置き場にテキストモデルが無い、または sha256 が一致しない
- WHEN 生成を始める
- THEN 生成を始めず(プール・wav・画像を変えない)、インストーラで入れ直すよう案内する。クラッシュしない

### S0059_01 生成を始めるたびにテキストモデルの GGUF を照合する

- GIVEN 置き場に、sha256 が一致するテキストモデルの GGUF がある
- WHEN 生成を始める
- THEN GGUF の sha256 を照合し、一致したので生成を始める

### S0059_02 前の照合が通っていても、そのあと壊れたら生成を始めない [否定]

- GIVEN 前の生成で照合が通った。そのあと GGUF の中身が変わり、sha256 が一致しなくなった(大きさは同じ)
- WHEN 生成を始める
- THEN 前の照合の結果を使わずに照合し直し、生成を始めない(S0055_08 の案内を出す)

### S0059_03 照合は Ollama に問い合わせずに置き場だけで判定する [否定]

- GIVEN `local-ollama` が応答しない。置き場の GGUF の sha256 が一致しない
- WHEN 生成を始める
- THEN Ollama に問い合わせず、テキストモデルが欠けているとして生成を始めない(S0055_08 の案内を出す。Ollama が応答しない時の案内は出さない)

### S0059_04 照合はテキストモデルを書き換えない [否定]

- GIVEN 置き場にテキストモデルの GGUF がある(sha256 が一致する・しないのどちらでも)
- WHEN 生成を始めて照合する
- THEN GGUF の中身・名前・置き場は変わらない(消す・置き直すことはしない。入れ直しはインストーラで行う)

### S0055_09 画像の重みが欠けていても生成は画像なしで完了する [境界]

- GIVEN 置き場に画像の重みが無い。テキストと音声は生成できる状態
- WHEN 生成を始める
- THEN 生成を始め、画像なしで完了する(S0036_10 / S0040_02)。完了の表示に、インストーラで入れ直すよう示す

### S0055_10 応援の発動は重みの状態に依存しない [否定]

- GIVEN 重みが揃っている、または欠けている
- WHEN 打鍵して応援が発動する
- THEN 発動は重みの状態を読まない。プールがあればその文言と wav で、無ければ定型文で応援する

## アンインストールと更新

### S0048_13 アンインストールで、アプリが保存したものをすべて消す

- GIVEN 重み・キャラクター(プール・wav・画像)・設定・統計が保存されている
- WHEN アプリをアンインストールする
- THEN 重みを含め、アプリが `{userData}` 配下に保存したものがすべて消える

### S0048_14 更新のインストールでは保存したものを消さない [否定]

- GIVEN 重み・キャラクター・設定・統計が保存されている
- WHEN 新しい版のインストーラを実行する
- THEN 保存したものは**変化しない**(消すのはアンインストールのときだけ。重みの扱いは S0055_06)
