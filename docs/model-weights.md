# 要件: モデル重みの取得

ローカルで生成するためのモデル重みを、利用者が始めたときに取得する。取得の入口は 2 つ:
**インストーラで選んで進めたとき**(論点 0048。下の「インストール中の取得」)と、**アプリの中で始めたとき**(論点 0042)。
インストール中に取得しなかった・できなかった重みは、アプリの中で取得できる。
利用者にコマンドを打たせず、配布ページから手で落とさせない(論点 0010)。

取得する重みは 2 つ。

| 重み | 使うプロバイダー | 無いとき |
| --- | --- | --- |
| テキストモデル(論点 0030) | `local-ollama` | 生成を始められない(取得へ案内する) |
| 画像の重み(ベースモデル + LCM LoRA。論点 0041) | `local-sdcpp` | 生成は始められ、画像なしで完了する |

VOICEVOX の音声モデルは同梱するので取得しない(論点 0034 / 0044)。重みの置き場は `{userData}` 配下。
案内や操作の見た目は仕様化しない。

画像の重みの取得元(論点 0041。Hugging Face の公式のリポジトリから直接取得し、自分たちではホストしない。
sha256 は `decisions/decided/0041-image-base-model/config.yaml`):

| | リポジトリ | コミット | ファイル | サイズ |
| --- | --- | --- | --- | --- |
| ベースモデル | `gsdf/Counterfeit-V3.0` | `d8ce63b3eb8e9102e54b3fcc07f9cb7a28ef30fc` | `Counterfeit-V3.0_fix_fp16.safetensors` | 2034 MB |
| LCM LoRA | `latent-consistency/lcm-lora-sdv1-5` | `cf2fced511dbe7e26c8d1d397e728fbab875db4b` | `pytorch_lora_weights.safetensors` | 128 MB |

テキストモデルの取得元は論点 0030 が決める。画像の重みの取得の前には、ライセンスへの同意が要る(`docs/licenses.md` S0047_02〜09)。

### S0042_01 テキストモデルが無ければ、メインウィンドウに取得の案内を出す

- GIVEN `providers.text = "local-ollama"` で、テキストモデルが取得されていない
- WHEN メインウィンドウを表示する
- THEN テキストモデルの取得の案内を出す。メインウィンドウのほかの操作(保存・切り替え・設定)はそのまま使える

### S0042_02 利用者が始めるまで取得の通信をしない [否定]

- GIVEN 重みが取得されていない
- WHEN アプリを起動する、メインウィンドウを表示する、または取得の案内を表示する
- THEN 取得の通信は発生しない。案内にはサイズ・取得元・ライセンスを示し、利用者が取得を始めたときに初めて通信する
  (インストーラで選んで進めたときも「始めた」にあたる。S0048_03 / S0048_04)

### S0042_03 取得中は進捗を示し、中断できる

- GIVEN 重みの取得中
- WHEN 利用者が進捗を見る、または中断する
- THEN 取得済みの量と全体の量が示される。中断すると通信を止め、それまでに取得した分は残す

### S0042_04 中断・通信断のあとは続きから取得する

- GIVEN 取得が途中で中断された、または通信が切れた(取得した分が残っている)
- WHEN 利用者が取得をもう一度始める
- THEN 残っている分の続きから取得し、最初から取り直さない

### S0042_05 ハッシュが一致しなければ使わない [異常系]

- GIVEN 取得が最後まで終わったが、sha256 が決められた値と一致しない
- WHEN 取得した重みを照合する
- THEN その重みを使わず、取得されていない状態のままにする。取り直しを案内する。クラッシュしない

### S0042_06 空き容量が足りなければ取得を始めない [異常系]

- GIVEN 置き場の空き容量が、取得する重みのサイズより小さい
- WHEN 利用者が取得を始める
- THEN 取得を始めず、空き容量が足りない旨を示す。通信は発生しない

### S0042_07 テキストモデルが無いまま生成を始めたら、生成を始めずに取得へ案内する [異常系]

- GIVEN `providers.text = "local-ollama"` で、テキストモデルが取得されていない
- WHEN 生成を始める
- THEN 生成を始めず(プール・wav・画像を変えない)、テキストモデルの取得の案内を出す

### S0042_08 外部のテキストプロバイダーを選んでいればテキストモデルを求めない [境界]

- GIVEN `providers.text` が外部のテキストプロバイダーで、テキストモデルが取得されていない
- WHEN メインウィンドウを表示する、または生成を始める
- THEN テキストモデルの取得の案内を出さず、生成は選んだプロバイダーの契約どおりに進む

### S0042_09 画像の重みが無ければ、設定画面に取得の操作を出す

- GIVEN `providers.image = "local-sdcpp"` で、画像の重みが取得されていない
- WHEN 設定画面を開く
- THEN 画像の重みの取得の操作を出す。取得が終わって照合が通れば、次の生成から画像の工程で使われる
  (取得を始める前に、ライセンスへの同意が要る。`docs/licenses.md` S0047_05〜07)

### S0042_10 画像の重みが無くても生成は始められる [境界]

- GIVEN `providers.image = "local-sdcpp"` で、画像の重みが取得されていない。テキストと音声は生成できる状態
- WHEN 生成を始める
- THEN 取得の案内で止めずに生成を始め、画像なしで完了する(S0036_10 / S0040_02)

### S0042_11 外部の画像プロバイダーを選んでいれば画像の重みの取得を出さない [境界]

- GIVEN `providers.image` が外部の画像プロバイダーで、画像の重みが取得されていない
- WHEN 設定画面を開く
- THEN 画像の重みの取得の操作を出さない

### S0042_12 取得で利用者の情報を送らず、監査ログにも記録しない [否定]

- GIVEN 重みの取得
- WHEN 取得元と通信する
- THEN 送るのは重みを受け取るための要求だけで、キー押下数・統計・プロフィール・API キーを含めない。
  外部プロバイダーへの送信ではないので、同意の記録と監査ログは変化しない

### S0042_13 応援の発動は取得に依存しない [否定]

- GIVEN 重みが取得されていない、または取得中
- WHEN 打鍵して応援が発動する
- THEN 発動は取得の状態を読まず、取得の通信も起こさない。プールがあればその文言と wav で、無ければ定型文で応援する

## インストール中の取得(論点 0048)

インストーラは、取得する重みを利用者に選ばせ、インストール中に取得する。取得・照合・続きからの取得は、アプリの中の取得
(S0042_03〜06)と同じ扱い。**取得がどう終わっても、インストールは完了する。** インストールは利用者ごとに行う。
画面の見た目は仕様化しない。

### S0048_01 インストーラで取得する重みを選ぶ。既定はテキストモデルだけ

- GIVEN 重みが 1 つも取得されていない機械
- WHEN インストーラが取得する重みを選ぶ画面を出す
- THEN テキストモデルと画像の重みを別々に選べる。既定は、テキストモデルが「取得する」、画像の重みが「取得しない」

### S0048_02 選ぶ画面に名前・サイズ・取得元を示す

- GIVEN インストーラの取得する重みを選ぶ画面
- WHEN 利用者が画面を見る
- THEN 重みごとに名前・サイズ・取得元が読める。画像の重みを選ぶと、ライセンスと利用の制限を示して同意を求める(`docs/licenses.md` S0047_02)

### S0048_03 利用者が進めるまで取得の通信をしない [否定]

- GIVEN インストーラを起動し、取得する重みを選ぶ画面を表示している
- WHEN 利用者がまだ先へ進めていない
- THEN 取得の通信は**発生しない**

### S0048_04 選んだ重みをインストール中に取得し、アプリは取得済みとして扱う

- GIVEN 利用者がテキストモデルを「取得する」のまま先へ進めた
- WHEN インストールが終わり、取得と sha256 の照合が通った
- THEN 取得中は取得済みの量と全体の量が示される。アプリを起動しても、テキストモデルの取得の案内(S0042_01)は出ない

### S0048_05 テキストモデルを外すと取得せず、アプリの中で案内が出る [境界]

- GIVEN 利用者がテキストモデルを「取得しない」に変えて先へ進めた
- WHEN インストールが終わり、`providers.text = "local-ollama"` のままアプリのメインウィンドウを表示する
- THEN インストール中にテキストモデルの通信は発生せず、アプリの中で取得の案内が出る(S0042_01)

### S0048_06 画像の重みは選んだときだけ取得する [境界]

- GIVEN 利用者が画像の重みを「取得しない」のまま先へ進めた
- WHEN インストールが終わる
- THEN 画像の重みの通信は発生しない。あとから設定画面で取得できる(S0042_09)

### S0048_07 取得を取り消してもインストールは完了する

- GIVEN インストール中の重みの取得
- WHEN 利用者が取得を取り消す
- THEN 通信を止め、インストールは完了する。それまでに取得した分は残り、アプリの中の取得は続きから取る(S0042_04)

### S0048_08 取得に失敗してもインストールは完了する [異常系]

- GIVEN 取得元と通信できない、または取得の途中で通信が切れた
- WHEN インストールを続ける
- THEN インストールは完了し、取得できなかった旨と、あとでアプリの中から取得できる旨を示す。その重みは取得されていない状態のまま

### S0048_09 ハッシュが一致しなければ使わず、インストールは完了する [異常系]

- GIVEN インストール中の取得が最後まで終わったが、sha256 が決められた値と一致しない
- WHEN 取得した重みを照合する
- THEN その重みを使わず、取得されていない状態のままにする(S0042_05)。インストールは完了する

### S0048_10 空き容量が足りない重みは取得を始めず、インストールは完了する [異常系]

- GIVEN 置き場の空き容量が、選んだ重みのサイズより小さい
- WHEN 利用者が先へ進める
- THEN その重みの取得を始めず(通信は発生しない)、空き容量が足りない旨を示して、インストールは完了する

### S0048_11 更新のインストールでは取得済みの重みを取り直さない [境界]

- GIVEN 取得済みで sha256 が決められた値と一致する重みがある機械
- WHEN 新しい版のインストーラを実行する
- THEN 選ぶ画面にその重みが取得済みと示され、その重みの通信は発生しない

### S0048_12 インストール中の取得で利用者の情報を送らない [否定]

- GIVEN インストール中の重みの取得
- WHEN 取得元と通信する
- THEN 送るのは重みを受け取るための要求だけで、キー押下数・統計・プロフィール・API キーを**含めない**。監査ログは変化しない(S0042_12)

### S0048_13 アンインストールで、アプリが保存したものをすべて消す

- GIVEN 重み・キャラクター(プール・wav・画像)・設定・統計・監査ログ・API キーが保存されている
- WHEN アプリをアンインストールする
- THEN 取得した重みを含め、アプリが `{userData}` 配下に保存したものがすべて消える

### S0048_14 更新のインストールでは保存したものを消さない [否定]

- GIVEN 重み・キャラクター・設定・統計が保存されている
- WHEN 新しい版のインストーラを実行する
- THEN 保存したものは**変化しない**(消すのはアンインストールのときだけ)
