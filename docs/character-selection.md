# 要件: 使用中のキャラクターの切り替え

保存済みのキャラクターから 1 つを使用中のキャラクターに選び、その文言と音声で応援する(論点 0032)。
保存・編集・削除は `docs/character-creation.md`、生成は `docs/pool-generation.md`。
切り替えは切り替え画面で行う(何を一覧に出すかは `docs/main-window.md` S0033_10〜12)。画面の見た目は仕様化しない。

### S0032_11 生成済みのキャラクターを使用中にする

- GIVEN プールのあるキャラクター C(生成中ではない)
- WHEN C を使用中にする
- THEN `activeCharacterId` を C の id にして保存する。次の応援から再起動なしで C のプールと wav を使う

### S0032_12 プールの無いキャラクターは使用中にできない [否定]

- GIVEN プールの無いキャラクター C
- WHEN C を使用中にしようとする
- THEN `activeCharacterId` を**変えず**、生成が済んでいない旨を返す

### S0032_13 生成中のキャラクターは使用中にできない [否定]

- GIVEN キャラクター C の生成が実行中(C に前回のプールがあっても同じ)
- WHEN C を使用中にしようとする
- THEN `activeCharacterId` を**変えず**、生成中である旨を返す

### S0032_14 生成中でも他のキャラクターに切り替えられる

- GIVEN キャラクター C の生成が実行中で、プールのあるキャラクター D がある
- WHEN D を使用中にする
- THEN 使用中は D になる。C の生成は中断されずに続く

### S0032_15 使用中のキャラクターが無ければ定型文で応援する [境界]

- GIVEN `activeCharacterId` が未設定 / 指す先が `characters` に無い / 指す先のプールが無い
- WHEN 応援が発動する
- THEN baseline 定型文で応援する(音声なし)。クラッシュしない。保存値は**書き換えない**

### S0032_16 切り替えは統計とトリガー設定を変えない [否定]

- GIVEN 使用中のキャラクター C、累計のキー押下数・トリガー設定
- WHEN 使用中を D に切り替える
- THEN 統計(キー押下数・応援履歴)とトリガー設定は**変化しない**

### S0032_17 renderer からの切り替え要求は main 側で検証する [不変条件]

- GIVEN renderer から届いた切り替えリクエスト
- WHEN main が受け取る
- THEN `id` が `characters` にあること・プールがあること・生成中でないことを main 側でも検証してから保存する
  (`security-rules.md`「入力と信頼境界」)

## 不変条件

- 使用中のキャラクターの切り替えは応援発動経路の外で行い、発動経路は保存された `activeCharacterId` と
  プール + wav だけを読む(外部依存ゼロ。providers を import しない)。
- 切り替えで外部送信は発生しない(localhost を含む)。
