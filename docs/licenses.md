# 要件: ライセンスとクレジットの表示

同梱物のライセンスと、VOICEVOX の**クレジット表記**を利用者に示す(論点 0043)。
**ライセンスはインストーラの画面にだけ示し、アプリの中には置かない。アプリに残すのは、話者を選ぶ所のクレジット表記だけ**(論点 0060)。
どの規約に基づくか・なぜこの置き方かは論点 0043 / 0060 に残す。表示の見た目は仕様化しない。

> S0043_01 / S0043_02 / S0043_05 / S0043_06 / S0047_01(アプリの中のライセンスの表示)は論点 0060 で欠番。

インストーラが示すもの:

| 対象 | 示すもの |
| --- | --- |
| VOICEVOX ENGINE | LGPL v3 で使っていること、ライセンスの全文、同梱した版のソースの入手先 |
| VOICEVOX の音声 | 選べる話者 4 つのクレジット表記と、各規約の URL |
| Ollama / stable-diffusion.cpp / テキストモデル | 著作権表示とライセンス文(MIT) |
| 画像の重み(Counterfeit V3.0 / LCM LoRA。論点 0041) | それぞれの名前・配布元・ライセンス名、ライセンスの全文(CreativeML Open RAIL-M / Open RAIL++-M)、利用の制限(論点 0047) |
| ONNX Runtime(`onnxruntime-node`)/ 人物を切り抜くモデル(u2netp。論点 0066) | 著作権表示とライセンス文(MIT / U-2-Net の Apache-2.0) |
| npm の依存 | ライセンスの一覧 |

選べる話者のクレジット表記(論点 0044 の 4 つ):
`VOICEVOX:四国めたん` / `VOICEVOX:春日部つむぎ` / `VOICEVOX:雨晴はう` / `VOICEVOX:玄野武宏(CV:ガロ)`

### S0043_03 話者を選ぶ画面に、その話者のクレジット表記を示す

- GIVEN キャラクター画面で話者の選択肢が出ている
- WHEN 話者を選ぶ
- THEN 選んだ話者のクレジット表記と、生成した音声をアプリの外で使うときはその表記と話者の規約に従う必要がある旨が示される

### S0043_04 表示は通信しない [否定]

- GIVEN 話者を選ぶ所のクレジット表記
- WHEN 表示する
- THEN 通信は発生しない。規約の URL は文字として示すだけで、アプリはその先を読みに行かない

### S0060_01 インストーラはライセンスとクレジットを示す

- GIVEN インストーラ(新しく入れる・更新する のどちらでも)
- WHEN インストールを進める
- THEN 上の表の対象それぞれについて示すものと、選べる話者 4 つのクレジット表記と規約の URL が読める。読むのに通信は要らない

### S0060_02 アプリの中にライセンスの表示を出さない [否定]

- GIVEN メインウィンドウ(どの画面でも)
- WHEN 画面を開く
- THEN ライセンスの全文・利用の制限・ライセンスの一覧を出す表示は**無い**。renderer にライセンスの文面を渡す API も**無い**。話者を選ぶ所のクレジット表記(S0043_03)は出す

## 画像の重みのライセンスへの同意(論点 0047)

画像の重み(Counterfeit V3.0 と LCM LoRA)のライセンスは、利用者にも**利用の制限**を守らせることを求めている。
そのため、**インストーラが画像の重みを置く前に**、ライセンスと利用の制限を示して**ライセンスへの同意**を取る(論点 0055 で入口をインストーラだけにした)。
アプリの中には同意の画面も同意の記録も無い。

> S0047_04〜09(重みを選ばない人・アプリの中での同意・同意の記録)は論点 0055 で、S0047_11 は論点 0054 で欠番。

同意の画面に示すもの:ベースモデルと LCM LoRA それぞれの名前・配布元・ライセンス名、ライセンスの全文、利用の制限。
文面は同梱する。画面の見た目は仕様化しない。

### S0047_02 インストーラは重みを置く前に、ライセンスと利用の制限を示して同意を求める

- GIVEN インストーラ(新しく入れる・更新する のどちらでも)
- WHEN 重みを置く手前まで進める
- THEN 同意の画面に示すものが読め、同意するかどうかを選べる。同意して先へ進めると、重みを置く(`docs/model-weights.md` S0055_01)

### S0047_03 同意しなければインストールを進めない [否定]

- GIVEN インストーラの同意の画面
- WHEN 利用者が同意しない
- THEN 先へ進めず、重みを**置かない**。インストールは完了しない(中止できる)

### S0047_10 同意の画面は通信しない [否定]

- GIVEN インストーラの同意の画面
- WHEN 表示する
- THEN 通信は**発生しない**(文面は同梱したものを示す)
