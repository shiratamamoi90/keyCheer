# 要件: ライセンスとクレジットの表示

同梱物・取得物のライセンスと、VOICEVOX の**クレジット表記**を、利用者がアプリの中で読めるようにする(論点 0043)。
どの規約に基づくか・なぜこの置き方かは論点 0043 に残す。表示の見た目は仕様化しない。

表示に含めるもの:

| 対象 | 示すもの |
| --- | --- |
| VOICEVOX ENGINE | LGPL v3 で使っていること、ライセンスの全文、同梱した版のソースの入手先 |
| VOICEVOX の音声 | 選べる話者 4 つのクレジット表記と、各規約の URL |
| Ollama / stable-diffusion.cpp / テキストモデル | 著作権表示とライセンス文(MIT) |
| 画像の重み | 決まったモデルのライセンス(論点 0041 が決まってから足す) |
| npm の依存 | ライセンスの一覧 |

選べる話者のクレジット表記(論点 0044 の 4 つ):
`VOICEVOX:四国めたん` / `VOICEVOX:春日部つむぎ` / `VOICEVOX:雨晴はう` / `VOICEVOX:玄野武宏(CV:ガロ)`

### S0043_01 設定画面からライセンスとクレジットの表示を開ける

- GIVEN メインウィンドウが表示中
- WHEN 設定画面でライセンスとクレジットの表示を開く
- THEN 上の表の対象(画像の重みを除く)それぞれについて、示すものが読める

### S0043_02 選べる話者 4 つのクレジット表記を全部示す

- GIVEN 使用中のキャラクターの話者が四国めたん(ほかの 3 つはどのキャラクターも使っていない)
- WHEN ライセンスとクレジットの表示を開く
- THEN 選べる話者 4 つすべてのクレジット表記と規約の URL が示される。使っている話者だけに絞らない

### S0043_03 話者を選ぶ画面に、その話者のクレジット表記を示す

- GIVEN 保存画面で話者の選択肢が出ている
- WHEN 話者を選ぶ
- THEN 選んだ話者のクレジット表記と、生成した音声をアプリの外で使うときはその表記と話者の規約に従う必要がある旨が示される

### S0043_04 表示は通信しない [否定]

- GIVEN ライセンスとクレジットの表示、または話者を選ぶ画面のクレジット表記
- WHEN 表示する
- THEN 通信は発生しない。規約の URL は文字として示すだけで、アプリはその先を読みに行かない

### S0043_05 同梱ランタイムや重みが無くても表示できる [境界]

- GIVEN 同梱ランタイムが起動していない、または重みが取得されていない
- WHEN ライセンスとクレジットの表示を開く
- THEN 起動や取得の状態に関係なく、同じ内容が表示される

### S0043_06 表示は保存データを変えない [否定]

- GIVEN キャラクター・設定・統計が保存されている
- WHEN ライセンスとクレジットの表示を開いて閉じる
- THEN 保存データは変化しない
