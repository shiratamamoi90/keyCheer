# 要件: ライセンスとクレジットの表示

同梱物・取得物のライセンスと、VOICEVOX の**クレジット表記**を、利用者がアプリの中で読めるようにする(論点 0043)。
どの規約に基づくか・なぜこの置き方かは論点 0043 に残す。表示の見た目は仕様化しない。

表示に含めるもの:

| 対象 | 示すもの |
| --- | --- |
| VOICEVOX ENGINE | LGPL v3 で使っていること、ライセンスの全文、同梱した版のソースの入手先 |
| VOICEVOX の音声 | 選べる話者 4 つのクレジット表記と、各規約の URL |
| Ollama / stable-diffusion.cpp / テキストモデル | 著作権表示とライセンス文(MIT) |
| 画像の重み(Counterfeit V3.0 / LCM LoRA。論点 0041) | それぞれの名前・配布元・ライセンス名、ライセンスの全文(CreativeML Open RAIL-M / Open RAIL++-M)、利用の制限(論点 0047) |
| npm の依存 | ライセンスの一覧 |

選べる話者のクレジット表記(論点 0044 の 4 つ):
`VOICEVOX:四国めたん` / `VOICEVOX:春日部つむぎ` / `VOICEVOX:雨晴はう` / `VOICEVOX:玄野武宏(CV:ガロ)`

### S0043_01 設定画面からライセンスとクレジットの表示を開ける

- GIVEN メインウィンドウが表示中
- WHEN 設定画面でライセンスとクレジットの表示を開く
- THEN 上の表の対象それぞれについて、示すものが読める(画像の重みは S0047_01)

### S0043_02 選べる話者 4 つのクレジット表記を全部示す

- GIVEN 使用中のキャラクターの話者が四国めたん(ほかの 3 つはどのキャラクターも使っていない)
- WHEN ライセンスとクレジットの表示を開く
- THEN 選べる話者 4 つすべてのクレジット表記と規約の URL が示される。使っている話者だけに絞らない

### S0043_03 話者を選ぶ画面に、その話者のクレジット表記を示す

- GIVEN 保存画面で話者の選択肢が出ている
- WHEN 話者を選ぶ
- THEN 選んだ話者のクレジット表記と、生成した音声をアプリの外で使うときはその表記と話者の規約に従う必要がある旨が示される

### S0043_04 表示は通信しない [否定]

- GIVEN ライセンスとクレジットの表示、または話者を選ぶ画面のクレジット表記
- WHEN 表示する
- THEN 通信は発生しない。規約の URL は文字として示すだけで、アプリはその先を読みに行かない

### S0043_05 同梱ランタイムや重みが無くても表示できる [境界]

- GIVEN 同梱ランタイムが起動していない、または重みが取得されていない
- WHEN ライセンスとクレジットの表示を開く
- THEN 起動や取得の状態に関係なく、同じ内容が表示される

### S0043_06 表示は保存データを変えない [否定]

- GIVEN キャラクター・設定・統計が保存されている
- WHEN ライセンスとクレジットの表示を開いて閉じる
- THEN 保存データは変化しない

## 画像の重みのライセンスへの同意(論点 0047)

画像の重み(Counterfeit V3.0 と LCM LoRA)のライセンスは、利用者にも**利用の制限**を守らせることを求めている。
そのため、画像の重みを取得する前に、ライセンスと利用の制限を示して**ライセンスへの同意**を取る。入口は 2 つ:
インストーラで画像の重みを選んだとき(`docs/model-weights.md` S0048_01)と、アプリの設定画面から取得を始めるとき(S0042_09)。
画像の重みを取得しない人には求めない。外部プロバイダーへの送信の同意(`providers.consent`)とは別のもの。

同意の画面に示すもの:ベースモデルと LCM LoRA それぞれの名前・配布元・ライセンス名、ライセンスの全文、利用の制限。
文面は同梱する。画面の見た目は仕様化しない。

### S0047_01 設定画面のライセンスの表示で、画像の重みのライセンスと利用の制限が読める

- GIVEN 画像の重みを取得していない(ライセンスへの同意もしていない)
- WHEN 設定画面でライセンスとクレジットの表示を開く
- THEN Counterfeit V3.0 と LCM LoRA それぞれの名前・配布元・ライセンス名、ライセンスの全文、利用の制限が読める

### S0047_02 インストーラで画像の重みを選ぶと、ライセンスと利用の制限を示して同意を求める

- GIVEN インストーラの取得する重みを選ぶ画面
- WHEN 利用者が画像の重みを「取得する」にする
- THEN 同意の画面に示すものが読め、同意するかどうかを選べる。同意して先へ進めると、画像の重みを取得する

### S0047_03 インストーラで同意しなければ画像の重みを取得しない [境界]

- GIVEN 利用者が画像の重みを「取得する」にしたが、ライセンスへの同意をしていない
- WHEN 先へ進める
- THEN 画像の重みの通信は発生せず、ライセンスへの同意も記録されない。インストールは続けられ、テキストモデルの取得は選んだとおりに行われる

### S0047_04 画像の重みを選ばない人には同意を求めない [否定]

- GIVEN 利用者が画像の重みを「取得しない」のままにしている
- WHEN インストーラを最後まで進める
- THEN ライセンスへの同意を**求めず**、同意していなくてもインストールは完了する

### S0047_05 アプリの中で取得を始めると、取得の前に同じ表示と同意を求める

- GIVEN `providers.image = "local-sdcpp"` で、画像の重みが取得されておらず、ライセンスへの同意が記録されていない
- WHEN 設定画面で画像の重みの取得を始める
- THEN 取得の通信の前に、同意の画面に示すものを示して同意を求める。同意すると取得が始まる

### S0047_06 アプリの中で同意しなければ取得を始めない [否定]

- GIVEN 取得の前の同意の画面
- WHEN 利用者が同意せずに閉じる
- THEN 取得は**始まらず**、通信は発生しない。ライセンスへの同意は記録されない。設定画面の取得の操作は残る

### S0047_07 同意済みの人にはもう一度求めない

- GIVEN インストーラまたはアプリの中でライセンスへの同意をして、記録されている(取得は取り消し・失敗で終わっていない)
- WHEN 設定画面で画像の重みの取得を始める
- THEN 同意を求めずに取得が始まる

### S0047_08 同意したことと日時と、同意した対象の版を記録する

- GIVEN 同意の画面
- WHEN 利用者が同意する
- THEN `system.imageWeightsLicenseAgreement` に、同意した日時と、同意した対象の版が記録される(`docs/data-model.md`)

### S0047_09 取得する重みかライセンスが変わったら同意を取り直す [境界]

- GIVEN 記録されている「同意した対象の版」が、いまのアプリが取得する画像の重みとライセンスの版と違う
- WHEN 設定画面で画像の重みの取得を始める、またはインストーラで画像の重みを選ぶ
- THEN 同意していないものとして扱い、同意を求める

### S0047_10 同意の画面は通信しない [否定]

- GIVEN インストーラまたはアプリの中の同意の画面
- WHEN 表示する
- THEN 通信は**発生しない**(文面は同梱したものを示す)

### S0047_11 ライセンスへの同意は、送信の同意と監査ログを変えない [否定]

- GIVEN 外部プロバイダーへの送信の同意(`providers.consent`)と監査ログがある
- WHEN ライセンスへの同意をする
- THEN `providers.consent` と監査ログは**変化しない**
