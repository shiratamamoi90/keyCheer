# 要件: キャラ作成フォーム(入力と保存)

メインウィンドウのフォームでキャラのプロフィール(名前・性格・話者)を入力・検証し、
永続化する。保存されたキャラは「作成済み」として扱われ、以降は起動時に
メインウィンドウが自動表示されなくなる(`docs/main-window.md`)。

プール・wav の生成と、生成物での応援発動は本 spec の対象外(別 change)。
フォームの見た目・レイアウトは仕様化しない(デザイン判断)。

`hasCharacter` の判定は `docs/data-model.md`「`hasCharacter` の判定」を正本とする。

## 確定事項(2026-07-26)

| 項目 | 確定 |
| --- | --- |
| 名前の文字数上限 | 20 文字(コードポイント単位) |
| 性格の文字数上限 | 200 文字(コードポイント単位) |
| 話者一覧の取得元 | VOICEVOX `/speakers`(localhost:50021) |
| 保持できるキャラ数 | 1 キャラのみ(保存は上書き) |

### S0019_01 必須項目が揃うまで保存できない

- GIVEN キャラ作成フォーム
- WHEN 名前または性格が空のまま保存しようとする
- THEN 保存は行われず、不足している項目が示される(複数欠けていればすべて示す)

### S0019_02 名前と性格の長さ制約 [境界]

- GIVEN キャラ作成フォーム
- WHEN 名前または性格に上限を超える文字数を入力する
- THEN 保存は行われず、超過している旨が示される
  - 文字数は**コードポイント単位**で数える(絵文字・サロゲートペアで上限が半減しない)
  - 上限ちょうどは受理する

### S0019_03 前後の空白は無視する [境界]

- GIVEN 名前または性格が空白文字のみ、あるいは前後に空白を含む
- WHEN 検証する
- THEN 前後の空白を除いた値で判定し、空白のみの入力は未入力として扱う。
  保存される値も前後の空白を除いたものになる

### S0019_04 話者を選ばないと保存できない

- GIVEN 名前と性格は入力済み、話者が未選択
- WHEN 保存しようとする
- THEN 保存は行われず、話者の選択が必要である旨が示される

### S0019_05 話者一覧を VOICEVOX から取得する

- GIVEN VOICEVOX が起動している
- WHEN フォームを開く
- THEN `/speakers` を取得し、話者 × スタイルを 1 次元に平坦化して選択肢として表示する。
  選んだスタイルの ID が `character.voicevoxSpeakerId` に入る

### S0019_06 VOICEVOX 未起動でも画面は壊れない [異常系]

- GIVEN VOICEVOX が起動していない、または応答が想定外の形
- WHEN フォームを開く
- THEN 例外を投げず、話者一覧が取得できない旨と起動を促す案内を表示する。
  フォーム自体は開けたまま、話者未選択のため保存はできない

### S0019_07 話者一覧の取得は localhost に閉じる [不変条件]

- GIVEN 任意の状態
- WHEN 話者一覧を取得する
- THEN 通信先は VOICEVOX(localhost)のみで、外部への送信は発生しない

### S0019_08 保存するとプロフィールが永続化される

- GIVEN 必須項目がすべて妥当
- WHEN 保存する
- THEN `character` に名前・性格・話者 ID が保存され、次回起動時も読み出せる。
  既存のキャラがあれば上書きする(1 キャラのみ)。
  画像パスやプールを勝手に作らない(生成は別 change)

### S0019_09 保存に失敗した場合 [異常系]

- GIVEN 永続化に失敗する(書き込み権限が無い等)
- WHEN 保存する
- THEN クラッシュせず、保存できなかった旨を表示する。
  キャラは未作成のまま扱われ、応援は baseline 定型文のまま継続する

### S0019_10 renderer からの入力は main 側でも検証する [不変条件]

- GIVEN renderer から届いた保存リクエスト
- WHEN main が受け取る
- THEN フォーム側の検証に依存せず、main 側でも必須・型を検証してから永続化する
  (`security-rules.md`「入力と信頼境界」)

## 不変条件

- フォームの検証は**純粋関数**として切り出し、Electron / DOM に依存させない。
- renderer は engine 実装・providers・agent を import しない。
- 話者一覧の取得は localhost のみ。外部送信は発生しない。
- 保存するのはプロフィールのみ。プール・wav・画像は生成フローの責務。
