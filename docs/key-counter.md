# 要件: キーカウント

全アプリ横断でキー押下回数をカウントし、応援の発動に使う累計カウントだけを保存する(論点 0081)。入力内容は一切記録しない。

### S0011_01 キー押下でカウント加算

- GIVEN 現在の累計カウントが N
- WHEN 任意のキーが1回押される
- THEN 累計カウントは N+1 になる(押されたキーの種類・内容は保存しない)

### S0011_02 同時押し・複数キーもそれぞれ1カウント

- GIVEN カウントが N
- WHEN 2つのキーがほぼ同時に押される
- THEN カウントは N+2 になる(イベント単位で数える)

### S0011_03 キーリピート(押しっぱなし)

- GIVEN OS の自動リピートで同じキーが連続して送られる
- WHEN uiohook-napi がリピートイベントを発火
- THEN **生イベントごとに 1 カウント**(デバウンスしない)。リピート抑制は Phase 1 では行わない

> S0011_04〜S0011_08(アクティブ判定・アクティブ秒数の累積・KPM 窓と `activeThresholdSec` の独立)は論点 0081 で廃止し、欠番
> (応援に要らないアクティブ時間を数えるのをやめ、`triggers.activeThresholdSec` を消した。KPM 窓が 60 秒固定なのは `speed-zone.md`)。

### S0081_01 累計カウントは再起動をまたいで続く

- GIVEN 累計カウントが N のまま終了した(終了前に保存した)
- WHEN 次に起動してキーが 1 回押される
- THEN 累計カウントは N+1 になる(通常の応援・節目の応援はこの累計カウントの倍数で出る。`cheer-trigger.md`)

### S0081_02 キーを打っても累計カウントのほかは保存しない [否定]

- GIVEN 起動している
- WHEN キーが押され、累計カウントを保存する
- THEN 保存されるのは累計カウント(`stats.totalKeyCount`)だけで、日ごとの押下数・アクティブ時間・応援ごとの記録は**作られない**

### S0011_09 除外設定(Phase 1 では未実装)

- GIVEN 設定スキーマに `system.excludedApps: []` / `system.excludedKeys: []` が存在
- WHEN 起動・キー押下
- THEN Phase 1 ではこれらの配列は参照されない(常に全アプリ・全キーを対象)。スキーマだけ用意し将来の change で実装する

## 不変条件

- 押下されたキーの**種類・並び・文字を保存しない**(カウンタのみ更新)。
- カウンタはメモリ上で加算し、定期的にディスク(electron-store)へ保存する。
- 保存するのは応援の発動に要る累計カウントだけ(論点 0081)。KPM 算出窓(60 秒)はコード固定で、保存しない。
