# Baselines

すべての探索ループ実験(experiments/)の比較基準。応援メッセージ生成は非決定的なので、
「baseline をどれだけ上回ったか」でのみ評価する。baseline 自体は決定的なので specs/ で仕様化し TDD 対象にする。

## メッセージ生成の baseline

- `template` … 定型文ジェネレータ。状況(count / type / zone)ごとに固定テンプレートから選ぶ。
  Ollama 未起動時のフォールバックと同じ実装を流用する。レイテンシ・契約遵守の下限基準。
- `zone_blind_prompt` … 速度ゾーンを渡さない現行プロンプト。プロンプト改善実験の比較対象。

## 評価軸(指標)

- 状況適合度(人手スコア)
- 多様性(ユニーク率)
- 生成レイテンシ(ms)
- 契約違反率(30文字超過・空・複数文)

新しいプロンプト/モデルは、上記 baseline に対する相対値で良し悪しを判断する。
